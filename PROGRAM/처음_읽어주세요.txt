Librarian System Server 0.4.1

[처음 사용하는 분]
먼저 Node.js 22.13.0 이상을 설치하세요. 현재 LTS 버전을 권장합니다.
공식 다운로드: https://nodejs.org/
일반 배포 ZIP에는 Node.js가 포함되지 않습니다. 설치 후 실행 파일을 여세요.
Android/Termux는 PROGRAM/안드로이드_Termux_준비.sh로 실행 환경을 준비하세요.

1. 이 ZIP을 원하는 폴더에 압축 해제합니다.
2. Windows: PROGRAM\1_서버_실행.bat
   macOS: PROGRAM/macOS_서버_실행.command
   Linux/Termux: PROGRAM/1_서버_실행.sh
3. RisuAI에는 PROGRAM/plugins 폴더의 필요한 플러그인 JS를 직접 설치합니다.
4. RisuAI 플러그인의 서버 설정에서 Librarian System Server에 연결합니다.

[기존 사용자 업데이트 - 가장 쉬운 방법]
Windows에서는 업데이트.bat, macOS에서는 업데이트.command, Linux/Termux에서는 업데이트.sh를 실행하세요.
명령어를 직접 입력할 필요가 없습니다.

업데이트 메뉴
1. 이 폴더의 서버를 최신 버전으로 업데이트
2. 다른 기존 설치 폴더를 업데이트
3. 미완료 업데이트 복구

0.3.51에서 처음 새 updater로 넘어오는 경우:
- 최신 배포 ZIP을 별도 폴더에 압축 해제합니다.
- 그 폴더의 업데이트 실행 파일을 엽니다.
- 2번 '다른 기존 설치 폴더를 업데이트'를 선택합니다.
- 기존에 사용 중인 Librarian System 최상위 폴더를 지정합니다.
- 이후부터는 기존 설치 폴더의 업데이트 실행 파일만 사용하면 됩니다.

[데이터 안전]
- 기존 DATA는 updater가 자동으로 보존하고 필요한 경우 DATA.next로 논리 이관합니다.
- 새 ZIP의 빈 DATA를 기존 DATA 위에 직접 복사하지 마세요.
- PROGRAM과 DATA를 사용자가 수동으로 교체할 필요가 없습니다.
- 실패하면 updater가 가능한 범위에서 이전 PROGRAM/DATA 쌍으로 복구합니다.
- 중요한 DATA는 정기적으로 별도 백업하는 것을 권장합니다.

[RisuAI 플러그인]
서버 updater는 RisuAI 내부에 설치된 플러그인을 자동으로 교체할 수 없습니다.
플러그인 업데이트가 필요한 경우 PROGRAM/plugins의 최신 JS를 RisuAI에서 직접 적용하세요.

[문제가 생겼을 때]
1. 업데이트 메뉴의 '미완료 업데이트 복구'를 먼저 실행합니다.
2. 실패 메시지를 확인합니다.
3. 상세 기록은 UPDATER/logs/latest.log에 있습니다.
4. DATA 폴더를 임의로 삭제하거나 빈 DATA로 덮어쓰지 마세요.
