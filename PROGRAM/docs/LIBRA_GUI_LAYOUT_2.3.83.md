# LIBRA 2.3.83 GUI 배치

열람과 설정, 작성을 목적별로 나눴습니다. 기존 책·서재 테마와 저장 형식을 유지합니다.

- 현재 열람대: 기억 생성 진입 버튼 하나, 분석·임베딩 설정 표시, 현재 작업의 진행·취소. 일반 작업 진행과 완료는 열람대 안에서 표시합니다. 기억 비교·수정 선택이 필요한 대화상자는 유지합니다.
- 작성실: 응답 작성, 인풋 작성, 서사 방향, 최근 결과, 고급 설정. 기존 LIBRA·GRADIA·Input Writer 설정과 실행·결과 화면을 재사용합니다.
- 설정: AI 연결, 기억과 검색, 참고 자료, 저장과 백업, 고급·진단으로 묶습니다. 설정 내용만 스크롤하며 저장·되돌리기 막대는 하단에 유지합니다.
- 기억 서가·인물 카드함·세계 도감·서사 연감: 목록에서 상세를 읽는 흐름으로 정리합니다. 세계·서사 검색과 종류 필터, 인물 검색을 제공하며 모바일에서는 목록으로 돌아갈 수 있습니다.
- 현재 채팅과 세계선 정보는 열람대의 접힌 상세에서 확인합니다.

새로운 모델 호출, 데이터 마이그레이션, 저장 계약 변경은 없습니다. 기존 기억 관리·백업·복구·근거 보기와 작성 지침 편집 경로를 유지합니다.

## 확인한 범위

- 독립 Chromium + 격리된 호스트/저장소: 데스크톱·모바일 메뉴, 작성 탭, 설정 저장, 저장값 재로딩, 되돌리기 즉시 활성화, 프롬프트 편집 이동, 검색·필터, 모바일 목록 복귀, 진행 상태의 열람대 내 표시.
- 기존 집중 회귀: 빠른 설정 저장, 실패 알림 닫기, 모델 요약, 기억 조회 수명주기·선택 정합성, 열람대 모델 프리셋 저장 및 작업대 경로.
- 테스트에서 실제 사용자 기억, RisuAI 애플리케이션, 외부 AI 모델을 사용하지 않았습니다. 실제 호스트에서의 동작은 미확인입니다.

구현 전 MemorySuite 전체를 DATA와 함께 별도 백업했습니다. 원본 및 백업의 파일 해시를 대조했으며, 배포 manifest·체크섬을 갱신합니다.
