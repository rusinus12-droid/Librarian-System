# LIA 설정 저장 시 작업실 유지

브랜치: `codex/lia-settings-save-in-place` (main `02c3c9a` 기준).

사용자 녹화에서 텍스트 AI 설정 저장 후 전체 작업실이 다시 읽히며 스크롤 위치가 바뀌는 것을 확인했다. 저장 동작의 `refreshPreview()`가 loading 화면과 `getContext()` 전체 재조회를 실행하고 있었다.

텍스트 AI 설정과 자료 길이 설정 저장에서 전체 새로고침을 제거했다. 실제 쓰기와 저장값 재확인은 유지한다. 텍스트 AI 설정은 정규화한 전체 설정을 재확인한 뒤 저장 기준 캐시·인증 표시만 갱신한다. 저장한 API 키 입력은 비우고, 키를 지운 경우에도 캐시를 갱신해 이후 빈칸 저장에서 이전 키가 돌아오지 않게 한다. 저장 중 새로 입력한 초안은 덮어쓰지 않고 미저장 변경으로 표시한다. 자료 길이는 기존 ARG 쓰기·재확인·실패 복구 계약을 유지하며, 값이 그대로인 경우 저장바만 닫는다.

검증:

- `lia_settings_save_in_place_test.cjs` 4개 통과: 실제 UI 클릭·저장 후 DOM 동일성, 추가 context 읽기 없음, 스크롤·포커스·선택 범위·details 유지, 저장/재저장/키 삭제 후 보존, 저장 중 입력 보존, 저장 실패와 재시도, ARG 저장 확인.
- `lia_random_chat_popup_test.cjs` 2개 통과.
- `lia_pocket_gui_runtime_test.cjs` 통과(기존 라우트 및 렌더 중 쓰기 없음 계약).

합성 호스트·저장소에서 실제 생산 렌더러와 DOM 이벤트로 검증했다. 실제 Risu에서 수정본을 설치한 후 녹화를 다시 측정한 결과는 아니다. 기존 DATA 변경은 제외했다. 저장·채택 등 Persona 작업의 화면 갱신 흐름은 이번 설정 저장 수정 범위에 포함하지 않았다.
