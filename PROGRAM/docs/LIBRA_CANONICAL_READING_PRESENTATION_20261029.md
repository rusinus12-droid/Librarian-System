# 정본 기억 읽기 화면의 영역 구분

구현 브랜치: `codex/libra-identity-link-review`. 사용자 요청에 따라 관련 LIBRA 변경을 로컬 main에 함께 커밋한다. 원격 푸시는 실행하지 않는다.

## 변경

기억 열람 본문이 Markdown 문자열 전체를 하나의 `<p>`에 넣어 제목 기호와 줄바꿈이 평문처럼 이어지던 문제를 수정했다. 종합 기억과 시간순 사건·인물과 관계·세계와 장면·내러티브와 미해결 문제·확정 사실과 불확실 정보·회상 키워드를 각각 제목·구분선·사실 목록으로 표시한다. 영역을 탭이나 접힌 패널로 나누지 않으며 같은 페이지에서 연속으로 읽는다.

문장 끝에 자동 생성된 `(근거: t3-a)` 형식의 턴 참조만 표시에서 제거한다. 여러 참조와 대소문자·전각 괄호를 지원한다. 일반 괄호 설명, 자연어 근거, 인용문 속 참조와 본문에 포함된 `t3-a` 같은 실제 문자열은 보존한다. 알려지지 않은 제목과 기존 자유 형식 문단도 버리지 않는다. 요약·축약을 수행하지 않는다.

제목·목차에 보이던 Markdown 제목 접두사도 표시에서만 숨긴다. 정본 텍스트·facts·evidenceSpans·검색/분석/복구 경로에는 변경이 없다. 기존 원문 근거 열람 기능도 유지한다. 사용자에서 유래한 내용은 HTML로 삽입하지 않고 텍스트 노드로 렌더링한다.

## 확인

- `libra_canonical_reading_presentation_test.cjs`: 7개 영역과 목록, 참조 표시의 제한적 제거, 자연어·인용 보존, 문단·목록 연속 줄, 사용자 정의 제목, 긴 본문 보존.
- `browser/libra_canonical_reading_sections_browser_test.cjs`: 실제 생산 GUI의 기억 서가→정본 선택→열람 경로, 모든 사실 유지, 영역 7개 동시 DOM 표시, 접힌 영역/별도 탭 없음, 표시 참조 제거, 원본 API 텍스트·근거 객체·저장 바이트 동일성, 390px 화면, HTML 비실행, 추가 모델 호출 없음.
- 기존 reader summary dedup, reading space, approved view layer 계약을 통과했다.

브라우저 검증은 합성 저장 데이터와 통제된 RisuAI API를 사용했다. 실제 RisuAI 앱·외부 제공자에 연결한 검증이나 전체 릴리스 검증은 아니다.
