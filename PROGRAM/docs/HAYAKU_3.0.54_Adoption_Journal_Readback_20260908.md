# HAYAKU 3.0.54 — 0.3.37 정본 채택 보완

2026-09-08. 전달본 HAYAKU 3.0.53의 새 실행 계약과 임베딩 관련 통합 코드는 보존하고, 현재 정본 3.0.43에 있었으나 전달본에서 누락된 저장 확인 저널 보호를 복원했다.

- 첫/강제 읽기가 rejected 또는 indeterminate이면 빈 저널을 변경 기준으로 삼지 않는다. 캐시를 무효화하고 쓰기 전에 오류로 중단한다.
- 저널 저장 뒤 정확한 물리 readback이 확인된 경우에만 캐시를 채택한다. 거절/no-op/readback 실패 뒤에는 다음 변경 전에 다시 읽는다.
- 성공하지 않은 저장은 fulfilled로 표시하지 않으며, 기존 미확정 항목을 보존한다.

기존 `hayaku_storage_reconciliation_journal_fault_test.cjs`를 실제 production 함수에 실행했다. 전달본 0/8, 복원본 8/8 통과. 이 시험은 저장소 오류 주입이며 실제 RisuAI GUI 또는 외부 모델 인증이 아니다.

저널 schema/키, 원문·패킷/정본 데이터, 정상 No-LLM capture, 새 실행 예산 정책을 변경하지 않았다. 패키지 0.3.37 / HAYAKU 3.0.54로 식별하며 나머지 네 플러그인과 서버/SDK는 전달본 바이트를 유지한다.

0.3.37은 개발 정본으로 검토한다. Librarian 단일 분석기 전환과 server_only 지원 제한은 통합 8차 및 10·11차 보고서를 따른다. 실제 호스트/모델 운영 인수와 잔여 설계 구현을 완료했다고 표시하지 않는다. 배포 ZIP의 빈 DATA를 기존 DATA에 덮어쓰지 않는다.
