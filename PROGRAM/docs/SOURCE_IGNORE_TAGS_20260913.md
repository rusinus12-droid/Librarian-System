# 사용자 지정 원문 제외 태그

LIBRA 2.3.113 / HAYAKU 3.0.120 / Flashback 1.0.81. 공통 Source Edit Consent 1.4.0.

## 사용

각 제품의 기존 **원문 수정 추적 모드** 아래에 **원문 비교에서 제외할 태그** 입력란과 **제외 태그 저장** 버튼을 추가했다.

- LIBRA: 설정실 → 일반·진단 → 원문 수정 동기화.
- HAYAKU: 구간 점검·복구 및 원문 추적 설정.
- Flashback: 고급 설정 또는 원문 수정 동기화 영역.

태그 이름을 꺾쇠 없이 한 줄에 하나씩 입력한다. 최대 32개, 이름당 64자이며 영문자로 시작하고 영문/숫자/하이픈/밑줄/콜론을 사용할 수 있다. 이름은 대소문자를 구분하지 않는다. 정규식·와일드카드는 지원하지 않는다. 설정은 제품별로 저장되며 다른 제품에 자동 전파되지 않는다.

기본 목록에는 `lb-xnai`가 표시된다. 기존 설정에 새 필드가 없어도 이 기본값을 사용한다. 기본 삽화 규칙은 이전과 같으며, 다음처럼 삽화 명령만 든 블록 또는 self-closing 태그를 제외한다. 내부에 실제 서사 문장이 있으면 보존한다.

```html
<lb-xnai id="scene">{{inlay::img-1}}</lb-xnai>
```

예를 들어 `my-decoration`을 추가하면 아래 두 형식은 비교·분석용 본문에서 제외된다.

```html
<my-decoration>표시 전용 내용</my-decoration>
<my-decoration value="표시 정보" />
```

사용자 태그는 내부 내용까지 제외한다. 닫히지 않은 태그는 끝까지 지우지 않고 보존한다. `my-decoration-extra` 같은 다른 이름에는 적용하지 않는다. 태그를 없애는 것은 설정 목록에서 해당 줄을 제거하고 저장하는 방식이다. 기존의 다른 내장 제어/삽화 정리 규칙까지 해제하는 기능은 아니다.

## 범위와 저장

기존 삽화 처리와 같은 canonical 본문 투영에 연결했다. 따라서 원문 수정 비교뿐 아니라 그 투영을 사용하는 기억 분석 입력에서도 등록한 블록이 제외된다. 원본 채팅 메시지와 저장된 기존 기억을 삭제하거나 덮어쓰지 않는다. 서사·사실로 기억해야 할 내용을 담은 태그는 등록하지 않는다.

이미 태그 내용이 분석된 과거 기억은 설정 저장만으로 재작성하지 않는다. 비교 정책 변경에 따라 기존 본문과의 차이가 나타날 수 있으며, 기존의 요청·승인 절차를 따른다. 원문 수정은 beforeRequest에서 감지하고 afterRequest 이후 검토하는 현재 정책을 유지한다.

설정은 기존 owner별 추적 설정에 ignoredTags로 저장하고 물리 재조회가 일치해야 성공으로 표시한다. 모드 전환 시 목록을 보존한다. 처리/요청 중 정책 변경은 거부하고, 새 요청은 진행 중인 태그 설정 저장이 끝난 뒤 정책을 읽는다. 재시작 시 설정을 읽으며, 메시지 비교 캐시에 정책 식별값을 반영하여 같은 raw 메시지라도 규칙 변경이 적용된다.
