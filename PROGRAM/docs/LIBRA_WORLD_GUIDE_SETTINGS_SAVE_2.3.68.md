# LIBRA 2.3.68 세계 도감·설정 저장 개선

세계 도감은 좁은 2열 소개 영역을 없애고 세계 개요 다음에 전체 폭 색인을 배치합니다. 항목 카드는 사용 가능한 폭에 따라 자동으로 열 수를 조정하며, 출처와 마지막 확인 시점은 카드 하단에서 자연스럽게 줄바꿈됩니다.

설정실의 `설정 저장`은 클릭 즉시 `저장 중…` 상태로 바뀌고 중복 클릭을 막습니다. 저장은 기존 트랜잭션과 물리적 readback 검증을 그대로 사용합니다. 성공하면 설정실과 상단 알림에 완료 상태를 표시하고, 실패하면 수정 중인 값을 유지한 채 원인을 표시합니다.

이 변경은 세계·기억 데이터 형식과 리콜·분석 동작을 바꾸지 않습니다.
