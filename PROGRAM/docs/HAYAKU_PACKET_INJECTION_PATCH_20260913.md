# HAYAKU 3.0.118 패킷 주입 수정 및 감사

2026-09-13. 대상: HAYAKU 3.0.117 → 3.0.118.

## 적용 범위

두 감사 문서를 독립 검토한 뒤 확인된 요청 분류 오탐, 부분 주입 검사, 억제 상태 표기를 수정했다. Gemini 고정 계약 역할 변경, 최소 계약 축소, 자동 재시도 증량, 서버 종료 처리, SDK 통합은 이번 변경에 포함하지 않았다.

### 1. 요청 분류

- 일반 설명의 `json schema`·`유효한 json`, 선택적 JSON 블록 언급을 전체 응답 형식으로 취급하지 않는다.
- system/developer 및 최신 user의 활성 지시를 메시지별로 검사한다. 과거 user, assistant, tool 응답을 출력 지시로 승격하지 않는다.
- 인용·코드 예시·해결되지 않은 조건부 지시는 전체 응답 의무로 승격하지 않는다.
- 직접 선언된 JSON/XML 응답, 배타 출력, 출력 형식 지정은 계속 제외한다. 한국어 `json으로만 출력해`도 감지한다.
- 제공자 이름·특정 캐릭터·프리셋 이름에 따른 예외를 추가하지 않았다. 텍스트 판정은 보수적인 문법 휴리스틱이며 임의 자연어의 의미를 완전히 판별하지는 못한다. 제공자 실제 response_format 메타데이터 연동을 새로 구현한 것은 아니다.

### 2. 부분 주입과 중복 호출

memo 하나가 존재한다는 이유로 전체 주입을 생략하지 않는다. 이번 인스턴스가 완전하게 조립한 마지막 출력에 대해서만, 메시지 내용·역할·순서 및 설정·현재 호스트 스코프·확정 채팅이 일치할 때 중복 생략한다. 기존 조립 결과를 반환하므로 nonce를 유지한다.

일부 조각 누락, 내용 변조, 역할/순서 변경, 중복 조각, 다른 입력·스코프·확정 채팅·설정에서는 기존 정리 및 재조립 경로를 사용한다. 호스트 확정 채팅을 읽지 못하면 중복 생략을 허용하지 않는다. 캐시 off/structural/native를 모두 검사했다. 중복 증명은 마지막 요청 한 건의 메모리 내 정보이며 사용자 저장소에 새 저널을 쓰지 않는다.

### 3. 진단

`runtimeSkeletonPreserved`, `completionSealPreserved`는 Boolean 형식을 유지하면서 실제 활성 작성 조각이 있을 때만 true다. 새 status 필드는 `preserved | suppressed | absent`를 사용한다. 구조화 출력 조기 제외에도 false 및 제외 사유를 기록한다. 컨텍스트 부족 시 원자 계약을 억제하는 보호는 유지한다.

## 검증 및 감사

- 새 `hayaku_packet_injection_integrity_runtime_test.cjs`: 패치 전 소스에서 최초 오탐 단언 실패, 패치 후 통과.
- 실제 플러그인 fixture에서 오탐/미탐, 메시지 경계, 과거 발화, 예시·조건, 부분 조각 여섯 조합, 변조·중복, nonce 유지, 호스트 편집·스코프·설정 변경, 세 캐시 모드, 부족한 컨텍스트, 억제 진단을 확인했다.
- 관련 테스트 19개 중 17개 통과. 두 실패는 패치 전 소스를 읽도록 하는 별도 preload로 동일한 실패 위치와 오류를 재현했다.
  - `hayaku_partial_outcome_binding_runtime_test.cjs:31`: 분리 실행 fixture의 `hayakuRecoveryBlocked` 미정의.
  - `hayaku_native_cold_start_contract_identity_test.cjs:30`: 기존 `false !== true` 단언 실패. 이번 변경에서 원인을 수정하지 않았다.
- 통과 범위에는 프롬프트/스키마, 바인딩, native repair 경쟁, 복구 저널, 저장 재확인, 긴 채팅 캐시, IPC 소유권, source-edit 및 재시작이 포함된다.
- 패킷 프롬프트 본문, 스키마, 저장 SDK 및 정규/복구 저장·저널 로직은 변경하지 않았다. 사용자 DATA를 대상으로 한 쓰기·마이그레이션은 수행하지 않았다.
- 최종 소스의 문법, 배포 메타데이터, 파일 해시 재확인 결과는 아래 증거 디렉터리의 `release-readback.json` 및 로그를 기준으로 한다.

증거: 작업공간 `review_artifacts/hayaku_packet_patch_20260913/`의 원본 백업, diff, 테스트 로그, `test-results.json`, `release-readback.json`.

## 남은 검증

실제 RisuAI UI와 Gemini/다른 제공자 호출은 실행하지 않았다. 따라서 Gemini 패킷 누락률 개선 수치나 실제 호스트 전송·모델 준수율을 보장하지 않는다. 텍스트 출력 형식의 모호한 선언 및 초대형 실제 채팅의 지연 측정도 별도다. 기존 실패 두 건과 앞선 Flashback 미해결 항목은 해결됐다고 간주하지 않는다.
