# LIBRA 2.3.86 헤더 모드 선택

LIBRA/GRADIA의 대분류 선택은 헤더의 이름 메뉴 한 곳에서 담당합니다. 빠른 설정과 작성실의 중복 대분류 선택기는 제거했습니다.

- LIBRA 선택 시 사서·플래너 설정을 표시합니다.
- GRADIA 선택 시 RP·소설 초안 설정을 표시합니다.
- 헤더 전환 후 작성실과 빠른 설정을 함께 갱신합니다. 공통 페이지 위치, 인풋 모드, 미저장 설정은 유지합니다.
- 기존과 같이 설정 저장 후 실제 적용됩니다. 저장값으로 되돌리면 헤더와 본문도 저장된 모드로 갱신합니다.

헤더 메뉴 클릭, 하위 설정 독립성, 저장·되돌리기, 공통 페이지 유지, 모바일 메뉴, 기존 빠른 설정과 작성실을 포함한 집중 테스트 7개가 통과했습니다. 격리 호스트·브라우저에서 확인했으며 실제 RisuAI와 외부 모델 호출은 수행하지 않았습니다.

수정 전 2.3.85 MemorySuite 전체를 백업하고 해시를 대조했습니다. DATA와 저장 형식은 변경하지 않았습니다.
