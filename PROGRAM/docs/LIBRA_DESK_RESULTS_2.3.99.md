# LIBRA 2.3.99 현재 열람대 및 작성실 대비 수정

현재 열람대의 buildBookJobSummary가 코어 내부 전용 asArray를 호출해 기억 작업이 있을 때 ReferenceError가 발생했다. 세 호출을 GUI 스코프의 guiAsArray로 교체했다.

작성실 안의 리콜 통계, GRADIA 단계 선택, 선택 단계 머리글, 빈 결과 및 결과 본문 카드에 밝은 종이 배경과 짙은 글자를 함께 지정했다. 선택 상태와 경고/실패 등 의미별 색은 유지한다. 다른 페이지의 색상과 데이터 처리에는 변경이 없다.

검증: 작업 경고가 있는 현재 열람대, 누락 배열 및 실행/완료/실패 작업 요약, LIBRA 통계 대비, GRADIA 선택/미선택 카드 및 빈 결과 대비를 Chromium에서 검사했다. 검사한 글자 대비는 모두 4.5:1 이상이다. GRADIA 작업대의 모드 전환, 저장/읽기, 프롬프트, 결과 및 모바일 검사도 통과했다. 모델 호출 0회, 브라우저 예외 0건. 실제 RisuAI 설치 검증은 수행하지 않았다.
