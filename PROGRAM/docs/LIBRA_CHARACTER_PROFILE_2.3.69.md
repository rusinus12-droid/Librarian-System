# LIBRA 2.3.69 인물 정보 확장

기억 분석에서 외형, 배경, 성격, 말투, 습관, 능력을 각각 생성하고 인물 카드의 기본 정보로 표시한다. 현재 위치·상태·목표, 지식, 소속, 관계는 별도로 표시한다. 소개 문장은 저장된 현재 상태에서 화면이 구성하며 별도 AI 요청은 하지 않는다. 기존 summary/description/profile/status 데이터는 읽기 호환을 유지한다.

## 저장과 갱신

- 기본 정보는 근거가 있는 항목을 누적한다. 이번 분석에 빠진 필드는 지우지 않는다.
- 이전 항목의 제거·교체는 명시적 근거를 요구한다. 일시적인 행동이나 감정을 성격·습관으로 일반화하지 않는다.
- 잘못된 항목은 따로 제외하고 정상 기억을 저장한다. 불확실하거나 전해 들은 정보는 정본에 남아도 현재 프로필에 확정 반영하지 않는다.
- 기존 기억을 자동 재분석하지 않는다. 새 분석부터 새 필드를 생성할 수 있다. 새 claim 종류를 지원하려면 이 버전의 플러그인이 필요하다.

## 검증

배포 소스를 실행한 합성 호스트·모델 테스트에서 기본 정보와 목표의 저장, 재시작 복원, 추가·제거, 수동 수정, 항목별 격리, 리콜, HTTP/SQLite 저장을 확인했다. 브라우저 검사는 데스크톱과 모바일 배치, 구형 필드 표시, 불필요한 빈 안내 제거 및 추가 AI 요청 없음을 확인했다.

실제 RisuAI와 실제 AI 제공자 호출은 검증하지 않았다. 기존 libra_unified_recall_vector_v1_test.cjs의 Planner 시나리오(line 21)는 패치 전 2.3.68 복사본에서도 동일하게 실패한다. 이 패치에서 해당 문제를 수정했다고 주장하지 않는다.
