# LIBRA 2.3.97 자동 기록 범위에 맞춘 읽기 화면

인물 카드함, 세계 도감, 서사 연감의 기본 읽기 화면을 현재 통합 분석이 자동 생성하는 필드에 맞췄다. 저장 형식과 정본, State, 교정 로직은 변경하지 않는다.

- 인물: 외형·배경·성격·말투·습관·능력, 위치·조건·목표, 지식·소속과 관계를 유지한다. 믿음·감정 등 비지원 필드, 임의 추가 정보, 소개문 fallback은 기본 화면에서 제외한다.
- 세계: 시간·조건, 장소 포함 관계, 소유·소지·관리·배치, 접근 권한·규칙을 유지한다. 별도 설명문과 비지원 추가 속성을 제외하며, 설명문 자동 생성을 기대하게 하는 빈 화면 안내를 수정한다.
- 서사: 남은 이야기·사건 연대기·마무리된 이야기만 제공한다. Arc·전환점·반복 소재·Lock 분류와 비지원 세부 표현을 기본 화면에서 제외한다. 구형 사건 이력 및 검색은 유지한다.

기존 데이터는 삭제하지 않는다. 이전 필드는 해당 관리 화면이나 정본 기억에서 확인할 수 있다. 지원되는 항목도 대화 근거가 없으면 비어 있을 수 있다.

검증: 인물 브라우저 41, 세계 29, 서사 25 항목 통과. GUI 필드와 통합 분석 producer의 일치 검사, 서사 모델과 이력 검사 통과. 저장 불변성, 검색과 관리 이동을 통제된 호스트에서 확인했다. 실제 RisuAI 설치 검증은 수행하지 않았다.
