# LIBRA 2.3.93 — 세계 도감 페이지

## 적용 범위

기존 LIBRA 메뉴, 헤더, 다른 페이지는 유지하고 세계 도감의 목록·상세 표시를 개선했다. 도감 전용 CSS와 읽기 모델을 사용한다. 기억 생성 프롬프트, 저장 스키마, API 호출 정책은 이번 도감 기능에서 변경하지 않는다.

- 종이색 목록과 명조 제목, 분류별 개수, 검색, 40개씩 목록 펼치기.
- 확인된 설명·상태·별칭, 연결된 장소·세력·사물·인물.
- 관리자·소유자·소지자·상위 장소를 구분하고, 소속 기록은 현재/과거 구성원과 역할로 연결한다.
- 규칙의 적용 범위와 조건부 예외를 표시한다. 장소에 포함된 규칙도 도감의 규칙 분류에서 읽을 수 있도록 표시용 항목을 만든다. 관리 화면은 원래 소유 기록으로 이동한다.
- 관계는 구조화된 참조로만 연결한다. 같은 이름이나 문장 속 언급으로 관계·소속·통행 허가를 추측하지 않는다.
- 현재 정보의 인용 근거와 확인 턴을 표시한다. 전체 변경 이력으로 표현하지 않는다. 기존 근거·관리 화면을 유지한다.
- 이름만 있는 항목, 빈 분류, 미확인 상태, 명시적으로 해제된 값, 사용자 교정을 별도로 설명한다.
- 추가 모델 호출과 도감 열람에 의한 정본·State 변경은 없다.

## 화면 비교

`review_artifacts/libra_world_atlas_20260912/index.html`은 승인 시안과 실제 페이지 렌더러의 1024px/390px 캡처 비교이다. 같은 폴더의 `actual.html`은 전체 LIBRA 소스와 통제된 호스트 및 가상 데이터로 동작하는 조작용 화면이다. `server.cjs`는 해당 검증 파일만 localhost:8769로 제공한다.

페이지끼리 비교하는 캡처는 실제 페이지 함수를 별도로 마운트했다. 전체 GUI 캡처는 `actual-1440.png`, `actual-1024.png`, `actual-390.png`이며 기존 메뉴·헤더를 함께 확인할 수 있다. 가상 소개 내용은 제품 코드에 포함하지 않았다.

## 기존 파일 손상 복구 — 도감 변경과 별개

작업 시작에 보관한 `LIBRA.before.js`부터 여러 함수가 중간에서 끊겨 다른 함수의 후반부와 이어져 있었다. 최초 오류는 `UNIFIED_MERGE_TWO_IDENTITIES];`였고, 인물 병합·분리, 재생, 배치, 리콜 등 다른 구간에도 같은 손상이 있었다. 사용자는 다른 동시 작업이 없다고 확인했다.

전체 플러그인 실행 검증에 필요한 복구로, 정상 문법을 확인한 `review_artifacts/libra_character_contract_patch_20260911/before/LIBRA.js`와 유일하게 일치하는 앞뒤 문맥 사이의 누락 부분을 원문 그대로 복원했다. 이미 검증된 최신 브라우저 소스 사본에서 복구한 후속 구간도 있다. 복구 내역은 `restored-*.txt`와 `syntax-gap-log.json`에 남겼다. 기존에 남아 있던 최신 소스 편집 승인 규칙과 프롬프트 변경은 보존했다. 과거 파일 전체로 교체하지 않았다.

세계 도감 바깥 GUI의 앞뒤 소스 영역은 작업 시작 사본과 바이트 단위로 일치한다. 복구는 런타임 누락 부분에 한정된다. 이 복구는 GUI 기능 추가와 구분해야 하며, 아래 회귀 검증 범위를 넘어 전체 시스템 인증을 의미하지 않는다.

## 검증

- `node --check` 통과.
- `libra_world_atlas_browser_test.cjs`: 28개 검사 통과, 페이지 오류 0. 실제 소스로 통제된 분석 결과를 정본에 저장한 뒤 도감 표시를 확인했고, 별도 가상 State로 시안 비교를 수행했다.
- 장소 안의 규칙을 규칙 분류에 표시하고, 관리 버튼이 원래 기록을 여는지 확인했다.
- 1440/1024/390px 가로 넘침 없음. 검색·Enter·빈 결과·분류·연결·구성원 이동·근거 펼치기·기존 관리 이동을 확인했다.
- 도감 조회 전후 정본과 State의 저장 바이트 보존. 기존 백그라운드 감사의 manifest 타임스탬프 및 마이그레이션 메타데이터는 별도로 취급했다.
- `libra_character_profile_browser_test.cjs`: 기존 인물 페이지 26개 검사 통과.
- 런타임 15개 테스트 파일 통과: identity, identity_split, world_replay, source_edit, lineage, recall_vector, source_review, source_preservation, failed_batch_fresh_retry, consumer_reference_material, consumer_transport, planner_consumer, gradia_consumer, memory_refusal_prompt, custom_prompt_pipeline_lock. 상세 결과는 `runtime-results.json` 참조.
- 실패 배치 테스트의 오래된 버전 고정값 2.3.86을 현재 2.3.93으로 갱신하고 실제 테스트를 다시 통과시켰다.
- 최종 브라우저 테스트용 사본에서 테스트 노출문 한 줄을 제거하면 제품 파일과 정확히 일치함을 확인했다.

실제 RisuAI 앱에 설치하거나 사용자의 실제 기억 데이터·실제 모델로 실행하지 않았다. Chromium 전체 플러그인과 통제된 호스트/제공자 검증이다. 전체 테스트 묶음 전체를 실행한 것은 아니다.
