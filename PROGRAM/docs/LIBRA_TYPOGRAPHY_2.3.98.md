# LIBRA 2.3.98 세 페이지 글꼴 정리

세계 도감 기준의 공통 typography CSS를 인물 카드함·세계 도감·서사 연감에 적용했다. 제목은 Batang/Georgia 30px(좁은 화면 26px), 소제목 17px, 본문과 색인 14px, 안내와 근거 위치 12px로 맞췄다. 본문·목록은 Malgun Gothic 계열이며 본문 줄간격은 1.85다. 주요 글자색 #493626, 보조 글자색 #705b46를 사용한다. 세 페이지 밖의 GUI와 데이터 처리에는 변경이 없다.

검증: 세 페이지 브라우저 95개 항목 통과. Chromium에서 제목·목록·본문의 computed font family, size, line-height, color가 세 페이지 모두 일치함을 확인했다. 1440/1024/390px 화면 검사 및 예시 화면 캡처를 확인했다. 실제 사용자 RisuAI 설치 검증은 수행하지 않았다.
