# LIBRA 2.3.85 공통 빠른 설정

LIBRA와 GRADIA의 빠른 설정을 응답·인풋·기억 세 탭으로 통일했습니다. 응답 탭의 공통 선택기에서 LIBRA와 GRADIA를 전환합니다. 작성실과 빠른 설정은 동일한 기본 설정 컴포넌트를 사용합니다.

## 배치

- LIBRA: 사서/플래너, 플래너 AI·계획 상세도·언어. 호출 예산과 오류 정책은 작성실의 고급 설정에서 변경합니다.
- GRADIA: RP/소설, 초안 AI·분량·언어·입력 처리. AIDE별 AI·순서, 경량/중량 호출 방식, 세부 전달 정책은 고급 설정으로 이동했습니다.
- 인풋: 사용 여부, 독립적인 RP/소설 모드, AI. 참고 자료와 호출 정책은 인풋 상세 설정에서, 지침은 전용 프롬프트 편집기에서 변경합니다.
- 기억: 기존 Librarian 분석기 사용 여부와 분석 AI. 분석 한도·참고 자료·프롬프트는 설정 → 기억과 검색 → 기억 분석·생성 한도에 모았습니다. 기억 화면은 응답 계열에 영향을 받지 않습니다.

기존 설정값과 저장 형식은 유지합니다. Librarian 사용 여부는 기존 분석기 활성화 설정에 연결하며, 별도의 자동 분석 정책을 새로 만들거나 변경하지 않습니다.

## 공통 조작

- 빠른 설정의 저장·되돌리기는 상단에 한 번만 표시합니다. 저장 결과는 같은 위치에 표시합니다.
- 닫기·배경 클릭·Esc는 창을 제거하며 미저장 초안을 유지합니다. 되돌리기는 저장값을 다시 불러옵니다.
- 바로가기는 창을 닫은 뒤 정확한 소유 화면을 엽니다. 작성실에서 내부 상태만 닫히고 창이 남던 갱신 누락을 수정했습니다.

## 확인한 범위

- 격리 Chromium 테스트 4개: 공통 탭, 실제 창 제거, Esc, 미저장 변경 유지, 연속 저장·되돌리기, LIBRA/GRADIA 전환, 인풋 독립성, 기억 설정의 계열 독립성, 기존 작성실·열람대·모바일 UI.
- 집중 런타임/계약 테스트 7개: 빠른 설정 경로, GRADIA 상태 권한·구조·완료·런타임 처리, 실패 알림, 모델 요약.
- 외부 AI 모델 호출 0회. 실제 RisuAI 애플리케이션과 실제 제공자 동작은 미확인입니다.
- 수정 전 2.3.84 MemorySuite 전체 633개 파일을 별도 백업하고 해시를 확인했습니다. DATA는 변경하지 않았습니다.
