# LIBRA 2.3.55 — 정본 분석 출력 상한 수정

2.3.54는 바이트 추정만으로 정본 요청을 거절하는 계산을 제거했지만, 별도로 `설정된 컨텍스트 - 256`을 출력 상한으로 적용했다. 컨텍스트 8,192, 출력 상한 24,000인 설정에서는 실제 요청의 출력 한도가 7,936으로 낮아졌다.

2.3.55는 정본 분석의 출력 예산을 이 컨텍스트 추정값과 분리한다. 요청 자체의 출력 예산, 프리셋 상한, 일치하는 모델의 최대 출력 metadata, 작업 예산 제한은 유지한다. 컨텍스트 압력 진단과 선택적 참고 자료 제외도 유지하며 대상 원문을 잘라내지 않는다.

최종 본문이 없고 제공자가 출력 한도 종료를 보고하면 `output_limit_before_final`로 분류한다. 화면에서는 응답 길이 한도 문제로 안내한다. 실행 진단에 완료 상태·종료 사유·추론 전용 응답 여부·실효 출력 상한·제공자가 보고한 usage를 함께 남긴다. 최종 답변이 없는데 성공한 기억을 만들거나 추론 텍스트를 기억으로 대신 저장하지 않는다.

추가 모델 호출과 자동 재시도는 추가하지 않는다. 이 수정이 모델의 최종 답변 생성이나 의미 정확도를 보장하지는 않는다. 실제 외부 모델 호출 검증과 모의 제공자 회귀 검증은 구분한다.
