# LIBRA 자동 인물 연결 검토

구현 기준 main `8d89781`, 작업 브랜치 `codex/libra-identity-link-review`. 사용자 요청에 따라 관련 LIBRA 변경을 로컬 main에 함께 커밋한다. 원격 푸시는 실행하지 않는다.

## 사용자 결정과 범위

자동 연결은 유지한다. 검토 대상도 즉시 적용되며 `applied:true`, `requiresApproval:false`로 노출한다. 검토 표시는 보류·차단·개별 승인 조건이 아니다. 사용자는 필요할 때만 연결 확인 또는 사실별 분리를 선택한다.

별칭은 별도 영속 ID가 아닌 문자열 배열이며 모델의 tempId는 배치 내부 참조다. 따라서 별칭 ID를 복원하는 방식이 아니라, 보존된 정본의 사실별 주체·대상·참조를 새 안정 ID에 배정하는 기존 분리 엔진을 사용한다.

## 구현

- 자동 이름 연결에 인물 ID, 원래 후보 ID, 이름 쌍, 배치·revision·원문 인용을 기록한다. 기존 Head는 이름·별칭 쌍을 검토 후보로 읽으며, 기록이 없던 당시의 상세 근거를 있다고 표시하지 않는다.
- 인물 카드함의 **자동 연결 검토** 버튼에서 별도 검토창을 연다. 원문과 턴 범위를 펼쳐 보고 **같은 인물 · 연결 확정** 또는 **서로 다른 인물 · 분리 검토**를 선택한다. 확정된 연결 표시, 목록 다시 읽기, 닫기를 제공한다.
- 병합·분리의 실행 화면은 **인물 병합·분리** 공통 창 하나로 통합했다. 인물 상세에는 **병합·분리 관리…** 버튼 하나만 두고 펼쳐진 별도 분리 폼을 제거했다. 자동 연결 검토의 분리 버튼도 같은 공통 창을 분리 모드로 열며, 닫기·저장 후 연결 목록을 다시 읽어 보여 준다. 동시에 두 대화창을 쌓지 않는다.
- 공통 창의 **병합**은 두 카드를 연결하고, **인물 분리**는 한 카드의 사실을 원래 인물별로 나눈다. 이전의 ‘병합 기록을 다시 나눔’ 설명과 숨겨진 구형 선택기는 제거했다. 병합 교정의 일시 중지로 실행하는 **병합 되돌리기**는 기존 기록·교정 기능으로 구분한다. 세계 항목에는 지원하는 병합만 제공한다.
- 분리 폼은 공통 창에서 한 번만 생성해 모드 전환·배경 화면 갱신 중 초안을 유지한다. 페이지와 팝업이 같은 캐시 DOM을 옮겨 쓰던 구조를 제거했다. 창 닫힘·채팅 범위 변경 뒤에는 비동기 결과를 적용하거나 새 저장을 시작하지 않는다.
- 상세 관리의 인물·관계 전환은 카드 박스 대신 **관리 페이지** 라벨과 평면 탐색 줄로 표시한다. 현재 페이지는 밑줄·강조색·`aria-current=page`로 구분한다. 다른 페이지의 콘텐츠 카드와 내부 탭에는 적용하지 않는다. 생산 렌더러에서 양방향 전환과 390px 화면을 확인했다.
- 검토 대상은 이름 단서만으로 연결된 후보다. 의미 판정 모델을 새로 호출하거나 원문에 특정 부정 문구가 있다는 이유로 자동 분리하지 않는다. 화면은 이를 ‘잘못된 연결 확정’이 아닌 ‘문맥 검토 필요’로 설명한다.
- 확정은 기존 correction journal에 저장한다. 현재 채팅·세계선·정본 경계·Head·preview가 달라지면 거절한다. 저장 실패 시 기존 Head와 journal을 복구하며, 재생·일시 중지·재개에 반영한다.
- 카드는 하나로 유지하되 `identityOrigins`에 원래 인물 ID와 이름을 각각 보존한다. 새 정본에는 `unifiedIdentityProvenance`로 인물 tempId→원래 ID, 사실 ID·역할 경로→원래 ID를 함께 저장하고 읽어서 확인한다. 표시 카드 ID를 바꾸더라도 사실의 원래 ID를 덮어쓰지 않는다. 기존 정본은 읽을 때 복원하며 저장된 본문을 다시 쓰지 않는다.
- 분리창을 열면 원본 ID로 역할을 자동 배정한다. 주체·관계 대상·중첩 참조 역할을 각각 처리한다. 추천 결과를 항목별 승인 없이 **현재 배정으로 분리 저장** 한 번으로 저장할 수 있고 필요한 항목만 수정할 수 있다. 검토 표시는 저장을 막지 않는다. 지원하는 최대 인물 수를 넘겨 같은 대상에 묶은 추천은 검토 표시를 남기며 원래 ID·정본을 보존한다. 실제 두 인물로 나눌 배정 자체가 없는 경우까지 임의의 사실을 다른 사람에게 넘기지는 않는다.
- 화면만 이름으로 인물을 다시 합치던 별도 병합을 제거해 화면과 저장된 ID가 일치한다.
- 분리의 임시 projection에서 고아 원래 인물 선언이 다시 살아나던 경로를 막았다. 이 카드를 만든 병합과 예전 연결 확인 작업만 임시 projection에서 제외하며, 영속 journal은 보존한다. 명시적 병합 전 두 ID의 사실도 현재 카드의 분리 대상에 포함한다. 과거 분리의 역할 배정도 따라가 원래 출처를 잃지 않게 한다.
- 기존 분리의 로컬 전용 제한을 해제했다. 서버·미러는 기존 conditional batch writer의 CAS·원자적 저장·물리 readback 경로를 사용한다. 다른 미지원 세계선·핸드오프 기능의 제한은 변경하지 않는다.
- 인용의 근사 보정 차단은 `LIBRA_QUOTE_EVIDENCE_GUARD_20261029.md` 참조.

- 기존 명시적 병합 13개·분리 13개 사례, 인용 검증 4개, 인물명 경계, 자동 점검·복구, 원문 부분 prefix 재개, correction GUI 계약을 실행했다.
