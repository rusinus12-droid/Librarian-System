# LIBRA 2.3.73 인물 병합 지식 선택

인물 관리 → 동일 항목 병합 → 남길 항목 선택 → 병합 내용 확인에서 지식 목록이 다를 때 세 가지 선택을 제공합니다.

- 원래 항목의 지식만 보존 (`source`)
- 남길 항목의 지식만 보존 (`target`)
- 둘 다 보존 (`both`): 남길 항목의 목록 다음에 원래 항목의 목록을 추가하고 정확히 같은 문자열만 한 번 남깁니다.

자동으로 어느 쪽도 선택하지 않습니다. 단일 값 필드나 지식의 명시적 삭제와 값 사이의 충돌은 기존 한쪽 선택 방식을 유지합니다.

선택은 기존 Correction Journal에 저장하고 현재 상태를 재생합니다. 두 목록의 원래 식별자, 값, 근거와 기존 교정 출처를 병합 출처로 함께 보관합니다. 정본 기억을 수정하거나 추가 모델 요청을 실행하지 않습니다. 병합 교정 일시 중지 시 원래 두 인물로 돌아가며, 재활성화하면 저장된 선택을 다시 적용합니다.

검증: 인물 병합 런타임 회귀(실제 플러그인, 모의 호스트/저장소), 브라우저에서 세 선택지와 둘 다 보존 커밋 검사. 실제 설치된 RisuAI와 실모델 호출은 검증 범위에 포함하지 않습니다.
