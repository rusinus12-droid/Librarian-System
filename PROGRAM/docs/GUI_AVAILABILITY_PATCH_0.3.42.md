# GUI 사용성 수정 0.3.42

- LIBRA 2.3.47: 호출 정책 패널을 모드 선택 버튼 밖으로 분리했습니다. 정책 입력 조작이 Planner/Classic 모드를 변경하지 않습니다. 임베딩 메타데이터 이전의 미리보기·진행·성공·오류를 같은 패널 안에 표시하고, 미리보기 전 적용 및 중복 실행을 막습니다.
- HAYAKU 3.0.57: 사용자 설정 총수와 그룹별 개수를 실제 스키마/화면에서 계산합니다. 현재 38개 설정을 표시합니다.
- Flashback 1.0.39: 유지보수 중지 요청은 실행 중 또는 물리 요청 대기 중에만 활성화됩니다. 화면의 작업 잠금 중에도 중지 요청이 가능하며 idle/완료/취소 후에는 비활성화됩니다. 완료된 체크포인트를 되돌리는 기능은 아닙니다.
- LIA 0.26.64: 생성 → 자료 설정에 자료 항목별 최대 문자 수(240~3000자)를 추가했습니다. 호스트 ARG에 저장하고 재읽기를 확인합니다. 저장 실패 시 이전 값을 복구하고 복구 결과도 검증합니다. 기존 설정 기본값은 변경하지 않았습니다.
- RETRACE 1.9.67과 공통 SDK는 그대로 사용합니다. 저장 데이터 형식과 원문/벡터 내용은 변경하지 않습니다.

검증: 실제 플러그인을 실행한 격리 Chrome GUI에서 모드 유지, 모바일 상태 표시, 설정 저장 버튼, HAYAKU 38개 설정 노출 및 개수, Flashback 취소 상태를 확인했습니다. LIA 저장 경로에는 누락/불명확 쓰기, 읽기 실패, 복구 실패, 동시 저장 회귀 검사를 추가했습니다. 실제 RisuAI, 원격 제공자, 과금 검증은 포함하지 않습니다.
