# LIBRA 2.3.81 — RP·소설 작성 지침과 인풋 작성

## 작성 권한과 범위

- RP는 사용자 행동, NPC·세계 반응, 아직 미정인 결과를 구분합니다. NPC의 선택을 무조건 최소화하지 않고 목적·성격·상황에 맞게 작성합니다.
- 입력에 없는 사용자 행동을 초안이 대신 썼다면 AIDE와 최종 작성에서 제거하고 종료 지점을 조정할 수 있습니다.
- 소설은 작가가 요청한 사건과 필요한 결과까지 완성합니다. 첫 초안의 끝 때문에 요청 범위를 줄이지 않으며, 요청과 관계없는 별도 전개는 시작하지 않습니다.
- 소설의 요청된 시간·장면 확장이 기존 종료 지점 휴리스틱에 의해 자동 거절되지 않도록 해당 RP 한정을 적용했습니다. 별도의 검사나 추가 AI 단계는 만들지 않았습니다.

## 입력 처리

RP와 소설 모두 설정실·빠른 설정·인풋 작성창에서 선택합니다.

- 자동: 입력을 완료된 행동, 시도, 이번 장면의 재료, 작가 지시로 구분합니다.
- 입력 이후부터: 입력의 장면 내용을 명시된 완료 수준의 시작 상태로 삼습니다. 시도를 성공으로 바꾸지 않습니다.
- 장면 안에 구현: 지정된 순서·위치에 입력 사건을 한 번만 구현합니다. 시작부에 강제로 넣지 않습니다.

기존 저장 키 `gradia_novel_draft_mode`를 유지하며 `classic`은 `auto`로 읽습니다. 기존 `input_inclusive`는 그대로 호환됩니다. 입력 처리는 두 작성 모드의 캐시 식별에도 반영됩니다.

## 인풋 작성창

- 인풋 모드와 GRADIA 초안 모드를 나란히 표시하고 독립적으로 바꿀 수 있습니다. 응답 엔진 자체를 자동 전환하지 않습니다.
- 모드와 입력 처리 변경은 작성 시작 시 기존 설정 저장 경로로 저장됩니다. 취소하면 저장하지 않습니다.
- 원문 다듬기: 행동·대사·강도·결정·결과를 유지하고 표현만 개선한 1개 결과를 만듭니다. 이미 자연스러운 원문은 그대로 반환할 수 있습니다.
- 대안 만들기: 핵심 의도와 고정 사항을 유지한 대안 3개를 만듭니다. 빈 입력에서는 현재 장면의 다음 선택을 제안합니다.
- 소설 대안은 기본적으로 현재 장면에 맞게 구성합니다. 주인공·NPC·외부 세계 구성은 선택 사항입니다. 관점 필드는 설명용이며 빠지거나 중복되었다고 정상 문장을 폐기하지 않습니다.
- 다듬기·대안 구성은 해당 작성과 재생성에 적용되는 선택입니다. 다른 모드 설정과 별도로 영구 저장하지 않습니다.
- 원본 선택, 후보 편집, 복사·입력창 삽입·전송은 기존 흐름을 유지합니다.

## 작업 범위와 확인 상태

추가 생성 호출이나 새 검사·검증 단계를 도입하지 않았습니다. 기존 재시도 안내도 원래 요청의 후보 수를 유지하도록 수정했습니다. 기존 정본·상태 저장 경로는 변경하지 않았습니다.

문법 및 기존 관련 회귀, 모의 제공자를 통한 RP·소설의 다듬기/대안 처리, 세 입력 처리 방식의 단계 전달, 독립 설정 저장을 확인했습니다. 실제 RisuAI 화면과 실제 모델의 문장 품질은 확인하지 않았습니다.
