플러그인 6종 GUI 재설계 시안

LIBRA · HAYAKU · Flashback · GRADIA · LIA · RE:TRACE 6개 플러그인의 현재 GUI 코드를 분석해 정보 구조(메뉴·화면)를 먼저 정리하고, 공통 디자인 시스템 위에 플러그인별 개성을 입힌 HTML 시안입니다. 모든 시안은 서버 없이 브라우저에서 바로 열립니다.

  • 각 시안 상단 막대에서 데스크톱 / 태블릿 / 모바일 폭 전환
  • 주소 끝에 ?device=mobile 을 붙이면 모바일로 시작
  • 상단 막대의 열기 버튼으로 대화상자·진행 화면 미리보기
  • GRADIA는 ?mode=rp 로 RP 모드 확인
  • blur·backdrop-filter 미사용 (모바일 GPU 가이드 준수)

공통 원칙 한눈에

원칙내용
모바일 GPU 안전backdrop-filter / filter:blur 금지. 불투명 면 + 1px 테두리. 그림자는 메뉴·모달·서랍 같은 떠 있는 요소에만.
한 화면 한 목적메뉴를 4~6개로 제한하고, 같은 설정·상태를 여러 곳에 두지 않음 (상태 칩 1개, 저장 막대 1개).
위험 작업되돌릴 수 없는 작업은 전용 대화상자 + 영향 범위 설명 + (큰 작업은) 확인 문구 입력 + 진행 단계 표시.
반응형컨테이너 쿼리 기반. 좁은 폭에서는 사이드바 → 하단 탭 (5개 초과 시 ‘더보기’ 시트).
접근성본문 12px 이상(보조 라벨만 11~11.5px, 현행 8~10px 대비 상향), 주요 터치 영역 38~42px(소형 버튼 제외), 포커스 링, 색만으로 상태를 구분하지 않음, prefers-reduced-motion 존중.

시안은 정적 HTML이며 실제 플러그인 코드(PROGRAM/plugins/*.js)는 변경하지 않았습니다. 자세한 분석과 이행 계획은 README.md 를 참고하세요.
