북쪽 정원의 기록실

열쇠의 문양은 잠금장치와 일치했으나, 문은 보름달이 뜨기 전까지 열리지 않는다.

아스텔은 오래된 온실을 지나 북쪽 정원의 끝에 닿았다. 기록실의 문은 이끼로 덮여 있었고, 문고리 아래에는 은색 문양이 새겨진 잠금장치가 있었다. (표본 본문 · M-25)

먼저 방식을 고르고 백업 파일을 선택합니다. 시안은 파일의 JSON 형식·LIBRA 백업 표식·기본 메타데이터만 검사합니다. 실제 digest·저장 레코드·현재 scope 자격 판정은 제품 연결 단계에서 수행해야 합니다.

이 시안에서는 파일 내용을 제품 저장소에 적용하지 않습니다. 검사 결과만으로 복원 가능하다고 판정할 수 없으며, 현재 채팅·캐릭터·작업 상태와의 자격 검사 및 영향 확인은 제품 단계에서 다시 해야 합니다.
