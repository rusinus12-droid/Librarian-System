# LIA mockup-to-product mapping

This inventory is the implementation map before replacing the current LIA view. The sole visual source is `index.html`, `lia.html`, `assets/suite.css`, `assets/themes.css` at the current mockup worktree state. Product renderers, API calls, data schemas, storage owners, safety checks, and analysis logic remain authoritative. The mockup's `suite.js`, fixture content, sample state, timers, and fake success actions are excluded.

## Existing product events and state bindings to retain

The old view is a single `renderPreview()` plus independently rendered asset/server panes. Its DOM-dependent integration currently lives in `bindFastGenerationStudio`, `bindPreviewTools`, `bindVisualAssetStudioUi`, `bindAction`, persona-side-panel handlers, module-picker handlers, recovery-panel handlers, and `activateTab`. Replace selectors/markup only after corresponding product actions have been rebound to new nodes. Preserve operation epochs and stale-target guards on rerender. Keep the existing `data-*` public/test hooks where useful, or add an explicit one-to-one selector migration in the same code change; do not keep old-view fallback markup or old style skin.
