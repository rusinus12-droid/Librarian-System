# LIBRA 2.3.57 — 항목별 기억 수용

아카이브 센터의 필드·항목별 검증 원칙을 LIBRA v4 계약에 맞춰 적용했다. 모델 응답을 수용하는 경로에만 정규화·격리를 추가했고, 저장된 artifact와 사용자 수정안의 엄격한 검증은 유지한다.

- 알 수 없는 최상위·개체·사실·typed value의 필드는 제외하고 정상 필드를 유지한다. 알려진 values wrapper 보정도 유지한다.
- 잘못된 개체·사실만 제외한다. 중복 ID는 임의로 하나를 선택하지 않고 모두 격리한다. 존재하지 않는 개체를 참조하는 사실, 누락·순환 의존성과 그 후속 사실도 격리한다.
- 직접 근거 span 일부가 잘못돼도 다른 유효한 근거가 있으면 유지한다. 근거가 전혀 남지 않은 항목은 제외한다. 규칙의 잘못된 예외를 삭제해서 더 넓은 규칙으로 바꾸지는 않는다.
- 유효한 사실이 하나 이상 남으면 기억을 저장·검색할 수 있다. JSON 자체를 읽을 수 없거나 schema가 다르거나 유효한 사실이 없으면 성공으로 표시하지 않는다. 자동 모델 수리 호출은 추가하지 않았다.
- `artifactValidation.admission`에 제외 위치·ID·사유·개수와 상태 영향 범위를 남긴다. `recordAdmissionDigest`를 정본·활성 참조·커밋 영수증에 연결하고 candidate/commit/replay에서 확인한다. 기존에 이 메타데이터가 없는 기억은 그대로 읽는다.
- 제외된 최신 업데이트와 같은 대상·필드의 과거 업데이트는 현재 상태로 승격하지 않는다. 정상적인 다른 상태는 기존 부분 상태 경로로 반영한다. 출처·대상이 불명확한 항목은 넓게 상태를 보류한다. 공백 구간 재생의 기존 연속성 조건은 유지한다.
- 작업 결과, 정본 참조와 열람대에 부분 저장을 표시한다. 기억 상세에서 제외 항목과 사유를 확인할 수 있다. 상태 실패와 벡터 실패가 정본을 되돌리지 않는 기존 구조는 유지한다.
- 현재 scope·원문 변경·세계선·저장 readback·취소·물리 요청 중복 차단 및 명시적 새 분석의 이전 작업 폐기는 유지한다.

회귀는 통제된 모델 응답을 사용하는 전체 플러그인 VM과 실제 로컬 HTTP/SQLite 저장·재시작을 대상으로 한다. 실제 RisuAI·외부 모델의 분석 품질·소요 시간 검증과 구분한다. 실행 결과는 작업 폴더 `review_artifacts/libra_partial_admission_20260908`에 기록한다.
