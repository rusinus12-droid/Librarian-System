# Librarian Updater 0.3.53 사용자 경험 패치

- 루트 업데이트 실행 파일을 인자 없이 실행하면 사용자 메뉴를 표시한다.
- 현재 설치 업데이트, 다른 기존 설치 업데이트, 미완료 업데이트 복구를 메뉴에서 선택한다.
- 0.3.51 등 구 설치를 갱신할 때 긴 bootstrap 명령을 직접 입력하지 않고 기존 설치 폴더만 지정한다.
- 사용자 모드는 새 버전 확인 → 공식 ZIP 다운로드 → 무결성/내부 검증 → 정책에 따른 실제 적용까지 한 번에 수행한다.
- Windows 더블클릭 모드는 결과를 확인할 수 있도록 종료 전에 대기한다. macOS .command도 완료 후 엔터 입력을 기다린다.
- 내부 오류 코드는 로그에 남기고 화면에는 가능한 한 이해 가능한 한국어 메시지를 먼저 보여준다.
- 서버 updater는 RisuAI 내부 플러그인을 자동 교체하지 않는다. 필요 시 PROGRAM/plugins의 JS를 RisuAI에서 직접 갱신한다.
- 고급 자동화/테스트용 기존 CLI 인자 동작은 유지한다.
