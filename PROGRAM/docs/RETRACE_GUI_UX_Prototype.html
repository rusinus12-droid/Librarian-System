비파괴 승계 흐름

각 단계는 이전 단계의 실제 readback을 통과해야 진행됩니다.

원본 보존
1 · 참여 Owner실제 설치·응답 Owner와 현재 데이터 참여 여부를 확정합니다.
2 · 저장 Gate참여 Owner의 plugin-only / mirror / server-only 일치를 확인합니다.
3 · 원본 지문각 Owner가 승계 전 immutable source fingerprint를 기록합니다.
4 · Owner 채택새 채팅에 prepare · adopt · verify를 Owner별로 실행합니다.
5 · 내구성 확인target readback과 source 불변을 모두 확인한 뒤 완료합니다.
