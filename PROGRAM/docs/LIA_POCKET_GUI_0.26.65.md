# LIA Pocket Studio 적용 — 0.26.65

승인된 `design_samples/lia-pocket` 샘플을 실제 LIA 렌더러에 적용했다. 밝은 흰색·라일락 카드, 네 개의 하단 메뉴와 모바일 대응 레이아웃을 사용한다.

## 화면 구성

- 내 페르소나: 실제 현재 채팅과 적용 Persona, 바인딩 관리, 초안 편집, 이미지·감정 에셋, Live Sync 상태·진행·최근 반영 상태.
- 만들기: 기존 네 가지 생성 방식과 세계관 자료 설정.
- 보관함: 기존 보관·불러오기·Persona 저장·삭제.
- 설정: AI 연결과 저장·서버 상세 메뉴.

편집·realtime·assets·server 내부 경로는 유지했다. 실제 저장, 바인딩, 복원, AI 호출은 기존 핸들러를 사용한다. 홈의 초안 편집은 현재 작업 결과를 편집하며, 표시된 현재 Persona를 자동으로 초안으로 바꾸거나 덮어쓰지 않는다. 채팅 전환은 RisuAI에서 수행하며 샘플의 가상 채팅 선택기는 제품에 넣지 않았다. Live Sync 완료 시 홈도 갱신한다. RE:TRACE의 저장 모드 일치 요구는 변경하지 않았다.

## 검증

- 문법 검사 통과.
- LIA 관련 9개 검사와 네이티브 분기·버전·공통 연동 관련 9개 검사, 총 18개 파일 통과. 초기 실패한 구형 사이드바 소스 문자열 검사는 새 설정 하위 경로 계약으로 갱신했다.
- 신규 `lia_pocket_gui_runtime_test.cjs`: 실제 렌더러 8개 경로, 중복 ID 없음, 기존 저장·동기화 조작 유지, 초안 보존, 호스트 문자열 이스케이프.
- 실제 렌더러에서 추출한 격리 브라우저 화면으로 홈, 생성, 설정, 바인딩 패널과 하단 메뉴 확인. 390px 모바일에서 가로 넘침 없이 하단 메뉴가 화면 끝에 배치됨을 확인.
- 기존 바인딩 복구 검사 13개 사례와 네이티브 분기 8개 사례 통과. 전체 회귀 배치는 재실행하지 않았다.

`design_samples/lia-pocket/implemented.html`은 제품 렌더러·CSS 및 메뉴 전환 함수를 이용한 격리 검증 화면이다. 테스트 데이터만 사용하며 실제 저장·AI·서버 동작을 수행하지 않는다. 실제 RisuAI에 다시 로드한 GUI, 실제 제공자 호출은 미검증이다.

제품 파일: `PROGRAM/plugins/LIA_Persona_Linker.js`. 수정 전 원본은 패키지 외부 `_backups/lia-pocket-20260911/LIA_Persona_Linker.js`에 보존했다.
