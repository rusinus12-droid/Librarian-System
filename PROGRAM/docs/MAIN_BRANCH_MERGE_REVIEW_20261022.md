## 리뷰에서 확인하여 수정한 결함

1. **LIA의 마지막 인덱스 검증이 이전 채팅 객체를 사용했다.** 채팅을 읽은 뒤 캐릭터를 다시 읽는 동안 채팅 순서가 바뀌면, 예전 채팅 데이터가 다른 인덱스의 채팅을 덮어쓸 수 있었다. 저장 결과 검증은 이 쓰기 이후에야 실패했다. 실제 런타임의 채팅 순서를 마지막 캐릭터 읽기에서 뒤집어 재현했다. 이제 새로 읽은 캐릭터의 해당 인덱스에 있는 채팅 ID를 확인하고, 바인딩의 동시 변경을 거부하며, 그 최신 채팅의 나머지 필드를 보존한다. 순서 변경·동시 필드 변경·동시 바인딩 변경 회귀 시험을 추가했다. LIA 버전은 `0.27.2`다.
2. **루트 `update-manifest.json`의 컴포넌트 버전이 소스보다 오래됐다.** `release_asset_contract_test.cjs`에서 현재 플러그인·Storage SDK와 불일치가 재현됐다. 기존 공식 생성기로 현재 버전과 동기화했다. 릴리즈 정책이나 백엔드 버전은 바꾸지 않았다.
