# LIBRA 2.3.63 — sensitive memory selection

The Librarian's fixed analysis contract now preserves source-supported events, relationship changes, personal boundaries and aftermath relevant to future continuity when the source includes adult themes. Sexual preferences, attitudes and identity labels require explicit source support and later relevance; gender, genre, appearance, roles and isolated reactions cannot establish them. Prior consent does not establish ongoing consent or a standing preference. Unsupported sensitive attributes are omitted independently of valid events and consequences.

This adapts the supplied World Manager's conservative extraction principles for factual memory analysis. Creative-writing guidance and narrative assistant prefill are not added. Existing non-graphic output, consent/refusal/coercion distinctions, evidence requirements, partial admission, refusal diagnostics and storage behavior remain intact. No new setting is required. Existing stored memory is not rewritten by this prompt change.

The controlled-provider runtime test verifies the actual outgoing system prompt, intact source input, JSON commit and refusal handling. It does not establish real-provider acceptance or the semantic accuracy of model responses. No live model requests or RisuAI GUI checks are performed for this change.
