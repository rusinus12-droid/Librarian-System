# 저장 위치 이동 후 사본 정리

Flashback, HAYAKU, LIBRA의 서버 연결 설정 → 고급 작업에서 사용할 수 있습니다.

## 기기의 중복 플러그인 데이터 정리

서버 단독으로 전체 이동을 완료한 뒤 **중복 pluginStorage 전체 삭제**를 누릅니다.
진행창에서 기기와 서버의 사본을 비교한 후 항목별 목록을 표시합니다.

- **사본 보존**: 기기 자료를 그대로 남깁니다.
- **이번 정리에서 제외**: 해당 항목을 건너뛰고 나머지 자료를 정리합니다.
- **삭제**: 선택한 기기 사본을 삭제합니다. 서버에 없거나 내용이 다른 사본을 삭제하려면 별도 확인란에 동의해야 합니다.

서버와 일치하는 사본만 기본 삭제 대상으로 선택됩니다. 읽을 수 없는 자료는 보존하거나 제외할 수 있습니다.
기기에 남긴 자료를 서버에 자동으로 덮어쓰지는 않습니다.
진행창에서 비교·정리 중인 항목과 처리 개수를 확인하고 **중단 요청**으로 남은 작업을 멈출 수 있습니다.
이미 정리한 항목은 결과에 표시하며, 중단 후 남은 자료를 다시 검사할 수 있습니다.

## 플러그인으로 이동한 뒤 서버 사본 정리

1. 저장 위치에서 **플러그인 단독**을 선택하고 **설정 적용**으로 전체 자료 이동을 완료합니다.
2. 고급 작업 → **이동 완료한 서버 사본 검토 · 삭제**를 누릅니다.
3. 목록에서 삭제할 사본을 확인하고 실행합니다.

플러그인 사본과 내용이 일치하는 서버 자료만 삭제할 수 있습니다.
보존한 대화가 참조하는 자료도 함께 보존합니다. 서버에 고정한 사본은 삭제하지 않습니다.
서버는 삭제 전에 백업을 만든 뒤 선택한 자료를 한 트랜잭션에서 삭제합니다.
삭제 표식을 새로 만들지 않으므로, 이후 서버로 다시 이동할 때 정리 작업이 기기 기억을 지우지 않습니다.

서버 사본 정리는 이번 기능을 포함한 `server.cjs`가 필요합니다. 이전 서버에서는 업데이트 안내를 표시합니다.
서버가 별도의 authority 프로필로 실행 중이면 해당 프로필이 광고하는 기능만 사용할 수 있으며, 기존 authority 보호를 우회하지 않습니다.
