# LIBRA · HAYAKU 채팅 알림 구분

작성: 2026-10-16 (한국 시간).

채팅 버튼의 이름을 숨기고 아이콘만 표시하는 호스트에서는 두 플러그인의 경고·시계 이모지가 같아 출처를 구별하기 어려웠다. 버튼 ID는 이미 서로 달랐다.

알림 아이콘 자체에 소속을 표시한다.

| 플러그인 | 항상 보이는 표시 | 상태 배지 |
| --- | --- | --- |
| LIBRA | 파란 바탕의 `L` | 지침 확인·실패: `!`, 지난 대화: 시계 |
| HAYAKU | 주황 바탕의 `H` | 보조 연결·기억 누락: `!`, Cold Start: 시계, 위치 안내: `i` |

색상과 글자를 함께 사용한다. SVG의 접근성 이름과 title에도 전체 플러그인 이름을 포함하고, 기존 버튼 name에는 구체적인 원인과 개수를 유지한다. SVG 내부에 공유 DOM ID·스타일·이벤트를 추가하지 않는다.

기존의 개별 등록 ID·클릭 경로·해제 경로를 사용한다. 알림 대상 선택, 모델 실행·승인, 저장·검색 정책을 바꾸는 변경은 없다.

`memory_attention_owner_identity_runtime_test.cjs`는 두 실제 플러그인을 로드하고 아이콘만 표시하는 공통 채팅 버튼 registry에 등록한다. 양쪽 로드 순서에서 소속 글자·접근성 이름·ID 분리·클릭 분리·개별 종료 정리를 확인한다. 알림 표시와 창 열기로 모델 요청이 발생하지 않는지도 확인한다. 기존 두 플러그인의 attention 회귀도 함께 실행한다.

Full/Min 빌드에서 같은 검사를 수행한다. 시각 미리보기는 실제 등록된 SVG를 Chromium으로 렌더링한 예시이며, 실제 RisuAI 설치 화면 캡처는 아니다.
