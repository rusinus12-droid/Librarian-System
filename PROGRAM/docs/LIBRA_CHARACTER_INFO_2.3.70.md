# LIBRA 2.3.70 인물 분석 형식 단순화

AI는 선택적인 character_info 항목에 category와 content를 작성한다. 대상, 근거, 시점과 확실성은 기존 사실 계약을 따른다. 내부 외형·배경·성격·말투·습관·능력·목표 필드는 코드가 연결한다. 모든 분류를 채울 필요는 없으며 추가 AI 요청은 없다.

알려진 분류와 한글 분류명은 해당 필드로 연결한다. 알 수 없거나 빠진 분류는 추측하지 않고 character_note로 정본에 저장한다. 이 정보는 리콜할 수 있지만 현재 프로필은 수정하지 않는다. 분류가 불명확한 삭제 요청도 설명 문장과 근거가 유효하면 기억으로 보존하며 실제 필드는 지우지 않는다.

내용·대상·근거 검증은 유지한다. 근거가 맞지 않는 항목은 제외하고 독립적인 정상 항목은 저장한다. 기존 세분화 응답도 계속 수용한다. 기존 저장 기억을 재작성하거나 자동 재분석하지 않는다.

합성 호스트·모델을 통한 저장, 분류 오기와 누락, 한글 별칭, 근거 불일치 격리, 리콜, 재시작 복원, 명시적 제거·해제와 기존 형식 호환을 검증했다. 실제 RisuAI 및 실제 AI 제공자의 응답 품질은 검증하지 않았다.
