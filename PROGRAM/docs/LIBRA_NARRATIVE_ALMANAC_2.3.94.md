# LIBRA 2.3.94 서사 연감

서사 연감 페이지의 기록 읽기 화면을 세계 도감과 같은 종이·책갈피 스타일로 개선했다. 다른 페이지와 생성 프롬프트, 저장 스키마는 변경하지 않았다.

- 남은 이야기: 과제·질문·약속 등의 종류와 미해결·막힘·미확정 상태, 현재 의미, 명시된 기록 시점.
- 사건 연대기: 동일 세션·동일 턴의 사건을 묶고 모든 사건 본문을 보존. 턴 미상 기록과 서로 다른 세션을 합치지 않는다.
- 이야기 흐름: 저장된 흐름·단계·중심 문제·전환점·반복 소재. 관련 인물/세계 ID와 arcId만 링크로 사용한다.
- 유지할 사실: 유지 중과 해제됨을 구분한다.
- 마무리된 이야기: 현재 State에 남아 있는 종결 항목 및 정본 기억의 당시 해결/종결 사실. 과거 종결 기록을 현재 해결 상태로 승격하지 않는다.

## 기억 이력

기존 Canonical Reader의 범위/세계선 검증 API를 이용해 사용자가 요청할 때 5묶음씩 읽는다. 현재 경로의 confirmed/current_sequence typed event와 resolved/closed thread 사실만 추려 표시한다. 임의의 산문이나 구형 텍스트를 파싱하여 사건·상태로 추정하지 않는다. 원래 기억 전체는 기억 서가로 이동해서 읽을 수 있다.

페이지 로딩은 전부 성공한 뒤에 반영한다. 실패 시 이전 페이지와 커서를 보존하며 재시도할 수 있다. 스코프·세계선·GUI 열기 세대·기억 revision·State 기준이 바뀌면 이전 조회 결과를 폐기한다. 기록된 인용의 원문 턴이 없는 이력은 턴 미상으로 표시한다. 기억 묶음의 끝 턴을 사건 발생일로 사용하지 않는다.

현재 사건과 이력 사건은 동일 세션/턴 안에서 본문과 근거를 비교하여 중복 표시하지 않는다. 현재 과제와 사건은 memoryId 및 source ref가 같은 경우에만 함께 읽기 링크를 만든다. 이름이나 문장 유사도로 관계를 추정하지 않는다.

## 검증과 한계

- 실제 전체 LIBRA 소스 + 통제된 RisuAI 호스트/모델의 Chromium 브라우저 검사 24개 통과. 정본 분석 저장 이후 해결 이력 조회, 사건 중복 방지, 현재 State/저장 보존, 추가 모델 호출 없음, 인물/세계/집필 이동, 1440/1024/390px 배치를 검증했다.
- 세계 도감 브라우저 회귀 검사 28개 통과.
- 읽기 모델/비동기 이력 검사: 상태 구분, 선택 필드, 근거 링크, 세션 분리, 미상 턴, 중복, 불변성, 페이지 실패, 재시도, 스코프 변경 응답 폐기, revision 무효화.
- 기존 서사 사건/그룹화/방향/소비자/완결 계약 검사 통과.
- 시안과 실제 렌더러를 736/390px로 촬영해 비교했다. 비교 데이터는 모두 가상이다.
- 실제 사용자의 RisuAI 세션이나 외부 모델을 통한 실사용 검증은 수행하지 않았다. 흐름·전환점·반복 소재 자동 생성 능력을 추가하지 않았다.
