# LIBRA 2.3.72 정본 장면 중복 요약 제거

정본 읽기 화면에서 본문과 같은 내용을 다시 표시하던 ‘이번 장에서 남은 핵심’ 카드를 제거했다. 정본 본문, 연결 항목, 현재 필드 근거와 상태 변경 정보는 그대로 읽을 수 있다.

`memory.summary`는 화면용 중복 표시만을 위해 존재하지 않는다. 기억 검색, sparse retrieval, 구형 기억의 fallback에 사용되므로 저장·검색 경로에서는 유지한다. 이번 변경은 표시 계층에만 적용되며 기존 정본 데이터나 자동 재분석을 건드리지 않는다.

검증에서는 본문과 근거 패널의 표시, summary 메타데이터 보존, 데스크톱·모바일 레이아웃, 기존 정본 리더 회귀를 확인한다. 실제 RisuAI 화면과 제공자 호출은 별도 검증 대상이다.
