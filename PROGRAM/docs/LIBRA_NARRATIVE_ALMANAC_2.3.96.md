# LIBRA 2.3.96 서사 연감 호환 패치

- 현재 분류의 제목·본문·사건 내용을 검색하며, Enter/찾기 및 검색 지우기를 지원한다.
- canonical_artifact v2/v3의 chronology를 읽기 전용으로 표시한다. evidenceRefs로 확인된 턴만 사용하고 위치 미상은 턴 미상으로 유지한다. 근거 위치를 인용 원문으로 꾸며내지 않는다.
- 구형 openThreads는 명시적으로 resolved/closed인 항목만 당시 종결 기록에 표시한다. 과거의 열린 과제를 현재 상태로 올리지 않는다.
- 관리 가능한 현재 Thread/Arc/Lock은 선택 ID를 관리 화면에 전달한다. 해당 관리 UI가 없는 항목과 과거 기록에는 기억 서가 안내를 제공한다.
- 정본 저장, State 생성, 교정 저널의 계약은 변경하지 않는다.

검증: 인물 41, 세계 28, 서사 27개의 브라우저 검사 통과. 서사 모델·이력 페이지·사건 투영·내러티브 계약 검사 통과. 실제 사용자 백업의 유효한 T1–T5 v3 기억은 8개 사건이 5개 턴 묶음에 보존되며, T6–T10 v4 기억은 11개 사건이 5개 묶음에 보존된다. 백업은 원본 변경 없이 격리된 렌더러로 확인했고 모델 호출은 0회였다.

실제 RisuAI 세션에 플러그인을 설치하고 복원·교정을 수행하는 검증은 하지 않았다. 실제 백업 원문은 테스트 fixture나 배포 패키지에 포함하지 않는다.
