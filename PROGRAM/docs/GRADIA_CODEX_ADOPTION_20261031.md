# GRADIA Codex 구현 채택과 Claude 변경 검토

기준은 로컬 `codex/aide-full-draft-recovery-atomic`의 `9e114ef`다. 작업 브랜치는 `codex/aide-recovery-hardened`이며, Claude의 `54064a7`과 공통 기준 `3877f4c`를 소스로 대조했다. 최초 채택 검증은 표시 버전 `0.28.2`에서 수행했다. 후속 사용자 요청에 따라 GRADIA를 `0.28.3`으로, 다른 플러그인 5개도 각각 패치 버전 하나씩 올려 main 커밋·푸시 대상으로 준비했다. 기존 DATA 변경은 보존한다.

## Claude 변경의 반영 여부

| 변경 또는 원칙 | 처리 | 근거 |
| --- | --- | --- |
| 인물·세계·플롯 모두 메타 초안을 복구할 수 있게 하는 공통 계약 | 채택 유지 | Codex 기준에 이미 분석·패치 계약으로 반영돼 있다. |

| 다른 Claude 브랜치 `b4266d2`의 Flashback 저장·LIBRA 반복 조회 최적화 | 추가 반영 불필요 | 이미 `main`과 이번 Codex 기준의 조상이다. GRADIA 변경도 아니다. |

## 이번 보강

- 문단 편집은 복제 문서에서 계산한 뒤 한 번에 게시한다. 대상 누락·해시 불일치·마지막 문단 삭제 같은 구조적 실패가 하나라도 있으면 성공한 연산도 되돌리고 원문·해시·문단 수를 보존한다. 동일 본문이나 중복 문장을 건너뛰는 정상 무변경은 다른 유효한 수정을 막지 않는다.
- 일반 문단 패치도 문자열 여부와 7,000자 한도를 검증한다. 긴 내용을 조용히 자르거나 객체를 문자열로 바꾸지 않는다. 전문 교체의 80,000자 상한도 유지한다.
- 거절 검사는 앞 1,400자 제한을 없애고 전체 문단을 검사한다. NFKC와 보이지 않는 문자 정리를 적용한다. 발화자가 명시된 인용 대사는 예외로 보되, 같은 문단의 다른 거절 표현을 지우거나 건너뛰지 않는다.
- 명시적인 편집 상태 안내, OOC·작성 계획, 사용자에게 진행 방향을 묻는 문장, 대안 메뉴도 복구 후보와 최종 전달 단계에서 검사한다. 일반 문단 편집으로 이런 내용을 새로 끼워 넣는 경우도 채택하지 않는다.
- 전달을 생략한 최종 초안은 `finalDraft`, 주입문, 마지막 안전 후보, 다음 실행의 재사용 후보에서 비운다. 전달 문자 수와 해시도 빈 본문 기준으로 맞춘다. 외부 기억 정리를 마친 뒤 내용 없는 생략 사유만 기록해 `LIB_READ_DRAFT_UNAVAILABLE`로 잘못 보고하지 않는다.
- 실패한 문단 트랜잭션의 적용 수 0과 건너뛴 연산을 진단 메타데이터에 기록한다.
- 공식 GRADIA 테스트 목록에서 빠진 6개 파일을 등록했다. 기존의 목록 일치 검증은 유지한다.

## 검증 범위

무해한 서고 장면과 모의 제공자를 사용해 실제 플러그인·파이프라인·`beforeRequest`를 실행한다. GUI 검증은 실제 결과 렌더러를 jsdom에서 실행한다. 새 모델 호출을 추가하지 않으며 기본 4회·heavyweight 8회 계약과 외부 기억 정리 계약을 함께 검사한다.

| 검증 | 결과 |
| --- | --- |
| 전체 `PROGRAM/tests/gradia/*.test.cjs` 순차 실행 | 664건 중 635건 통과. 실패는 임시 폴더 권한 오류 28건과 기존 그룹 소유권 결함 1건이다. |
| 읽기 연결 28건 재실행 | `TEMP`·`TMP`를 쓰기 허용된 작업 공간 내부로 지정하자 28/28 통과했다. 제품 코드나 검증 조건은 바꾸지 않았다. |
| 최종 소스의 복구·전달·GUI 집중 실행 | 114/114 통과. 이미 전체 실행에서 확인한 느린 상속 타임아웃·지연 시험은 이 집중 실행의 이름 필터에서 제외했다. 전체 실행 시작 후 추가한 `beforeRequest` 2건과 메타데이터 보강도 이 실행에 포함한다. |
| 그룹 소유권 실패의 기준 커밋 대조 | `3877f4c` 소스로 같은 시험을 실행해 `wrong-chat: 1 !== 0`을 재현했다. 이번 복구 변경의 회귀로 분류하지 않으며 전체 통과로 보고하지 않는다. |
| 테스트 목록 일치·구문·공백 검사 | `gradia_suite_test.cjs --list`, `node --check`, `git diff --check` 통과. |

## 남는 검증 경계

문자열 규칙은 장면의 의미와 품질을 완전히 판정하는 장치가 아니다. 알려진 메타 형식과 구조적 실패를 엔진이 거부하도록 보강했지만, 미지의 언어·표현·무관한 장면·이전 서사의 의미적 보존은 모델 판단과 실제 실행 확인이 필요하다. 모의 시험을 실제 RisuAI 응답, 외부 제공자의 판단 품질, 성능·과금 검증으로 해석하지 않는다.
