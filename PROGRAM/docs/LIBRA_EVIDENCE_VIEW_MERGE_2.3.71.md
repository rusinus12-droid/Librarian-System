# LIBRA 2.3.71 근거 화면 통합

기억 읽기 화면에 나란히 있던 **기억의 근거**와 **기록 계보**는 같은 정본 근거 체인과 같은 렌더러를 보여주고 있었습니다. 두 진입점을 **근거와 상태 반영** 하나로 합쳤습니다.

통합 화면은 다음 순서로 한 번에 보여줍니다.

1. 기억을 만든 원문 U+A
2. 원문에서 확정된 정본 사실
3. 로컬 현재 상태 적용 영수증
4. 현재 필드(Current Head)

통합 화면 안에서 같은 Evidence Drawer를 다시 여는 중복 버튼도 제거했습니다. 실제 세계선의 분기와 상속을 보여주는 `STORY LINEAGE` 화면은 별도 기능이므로 유지했습니다.

정본 근거 조회 API, 저장 데이터, 검증 규칙은 변경하지 않았습니다. 이번 변경은 읽기 화면의 중복 진입점과 표시 구조를 정리한 GUI 변경입니다.
