# LIBRA canonical memory network — A1 contract

A1 is a canonical registry transition on the approved A0 recall baseline. It preserves the existing shortlist, associative admission, BM25F/dense scorer, ranked-list fusion, gate, excerpt, and packing behavior. C2/D1 will replace that flow with the approved single frontier/scorer; A1 does not claim that engine is active. Normal runtime parity targets are `plugin_only` and `server_only`. Mirror tests remain migration evidence.

## Pure factory and interfaces

`PROGRAM/tools/libra_memory_network.cjs` exports `createMemoryNetwork({tokenize, adapters})`. `adapters.hash(serialized)` supplies a deterministic digest and optional `adapters.rowForUnit(unit,input)` supplies the original hydrated row. The factory performs no storage/provider calls, source rescans, clocks, timers, embedding, or automatic analysis. The runtime embeds its exact `toString()` through the unique `LIBRA MEMORY NETWORK` marker. `sync_libra_memory_network.cjs --check` and the LIBRA builder reject missing, duplicate, reversed, or stale factory markers before output assembly.

| Interface | Produces and consumes in A1 |
| --- | --- |
| `project({memory,source,frame,row})` | Frozen `EvidenceUnit[]`; one canonical candidate unit contains source/claim identities, representation/binding and token/entity/predicate/time postings. Claims remain separately identified inside the candidate. The row stays in a private WeakMap. |
| `upsert(units,{frame,row?,access?})` | Coverage with indexed units, canonical candidate count, identity coverage, and complete/partial status. Owns one active registry. Physical binding mismatch replaces the candidate and invalidates old leases. Frame changes require explicit invalidation. |
| `invalidate(refs,liveEpoch)` | Removes source IDs (`string` or `{sourceId}`) and their postings. Numeric live epoch advances the current frame; a complete live frame can also replace owner/scope/worldline/as-of/mapping. Epoch rewind rejects. |
| `discover(accessResults,registry?)` | One `SingleCandidate` per unit with original row and merged access evidence. Array results use `{unitId,kind,score}`; posting access uses `{tokens,entities,predicates,times,semanticIds}`. Semantic access does not require lexical overlap; lexical access does not require an embedding. |

`scoreCandidate` and `retrieve` are deliberately absent in A1; those interfaces belong to later implementation. Internal compatibility helpers `projectCanonical`, `createRegistry`, registry `upsert`, `invalidate`, `discoverCandidates`, `rows`, `capture`, `isCurrent`, and `diagnostics` support precise binding tests and subsequent adapters. Registry capture returns an opaque issued object: a JSON clone/forged lease cannot certify currentness. Candidates and projection/binding objects are frozen. Their original runtime rows remain mutable for the existing scorer, without changing registry identity. Access score is max per channel, and path bonus is always zero; repeated access never awards additional relevance.

## Identity is separate from authority

A complete `SourceObjectID` requires caller/runtime established `ownerNamespace`, `originScope`, source `objectUUID`, and `birthIncarnation`. Surface message ID, array position, same turn, same display name, changing body hash, or producer tempFactId does not prove those anchors. A copied source must have a new local UUID/incarnation with any origin link handled explicitly by its owner.

A complete stable `ClaimID` is runtime derived from the source object plus typed actor ID, target ID, predicate, direction, value, polarity, time, certainty, and explicit source anchors. Identical typed meaning and source attachment may preserve identity across text/revision changes. Changed meaning, negation, target/time/certainty, split/merge attachments, or different entities with the same name produce distinct IDs. Caller claim IDs are ignored. Duplicate matching claims have ambiguous one-to-one assignment and fall back to partial, revision-bound identities. Ambiguous legacy sources/claims remain revision/body-bound with partial coverage; this stage never launches corpus reanalysis or converts source-only/State/lore into confirmed events.

`EvidenceBinding` independently contains current owner/scope/worldline/as-of, active mapping, live authority epoch, source/analysis revisions, physical record key/digest, source digest, semantic digest, rendered hash, projection version, and embedding space. Representation identity binds text/projection/space separately from logical claims. Equal source/claim IDs do not authorize reuse of a changed vector or representation.

The registry's live epoch is supplied by the trusted runtime, never restored from a canonical payload. For `A(epoch7) → B(epoch8) → A(epoch11)`, source identity and A text hash may match but an epoch7 job/readset is invalid. Candidate replacement/revocation also invalidates its private issued lease even if a binding is later reused. Runtime restore generation is the existing nonrewinding `state.microRestoreGeneration`; server owner identity additionally binds the existing client data-instance/connection generation. Final readsets capture this frame privately and check owner, scope, worldline, restore generation, and active manifest revision before and after physical evidence reads. Existing response-boundary validation enforces the selected temporal view. A changed frame fails open through the existing consumer error path.

## Runtime capability and parity boundary

Every canonical hydrated row, including A0 associative rows, passes through `project → upsert → discover` before the existing batch scorer. Micro rows retain their current path until B1. The adapter returns original row and memory references; it never serializes, spreads, clones, or adds public JSON proof flags to capability-bearing memories. Existing canonical proof WeakMaps and final physical owner-store validation continue to supply authority. Projection identifiers themselves certify no physical authority. The network's final frame is attached to the original recall result in a private WeakMap and retained only in the existing bounded private readset registry.

`Runtime.lastMemoryNetworkDiagnostics` exports counts and coverage only, with no proof objects, raw body, rows, or lease handles. Counters cover inserted projections, upserts, merges, posting additions, discovery calls and invalidation calls. They do not claim to measure or fix full catalog preparation, hashing, vector reads or warm corpus cost; A2 owns those costs. No GUI, server tokenizer/SDK, provider/model config, shared pins, or installation is changed.

## Evidence

Projection tests cover semantic equivalence/change, split/merge, duplicate ambiguity, same-name entities, owner/scope/incarnation separation, revision-bound legacy IDs, postings, channel-independent discovery, merged accesses, frozen identity, revocation and ABA old-job rejection. The actual-hook parity test compares selected identities, delivered source text and complete provider-packet bytes against A0 for plugin_only graph OFF/ON and server_only, with nonce/timestamp as separately checked sidecars. A synthetic epoch advance at the actual final physical read rejects identical A bytes. A0's actual-hook regression and existing canonical/recall/freshness suites remain required. Mock providers and synthetic interleavings attest wiring/safety, not real-model accuracy or performance envelopes.
