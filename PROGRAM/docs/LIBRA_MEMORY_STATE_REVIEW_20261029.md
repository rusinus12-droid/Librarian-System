# 기억·상태 자동 반영과 사용자 검토

## 동작

원문·저장·현재 채팅/세계선 범위가 확인된 Micro 기억과 정본의 보류 사실을 사용자 반려 전까지 검색 근거로 사용한다. 상태 변경은 검증된 대상과 구조화 상태 계약을 유지하는 범위에서 자동 반영한다. 원문 변경, 저장 미확인, 다른 범위, 불명확한 대상·참조, 순환 포함 관계, 명시적 사용자 교정이나 더 새로운 근거는 우회하지 않는다. 상태에 적용할 수 없는 항목도 검증된 기억으로 사용할 수 있으며 검토 창에 상태 미반영 사유를 표시한다.

현재 상태는 저장된 정본/Head의 원본 바이트를 고치는 대신 읽기 시 자동 반영 결과를 합성한다. 동일 턴 충돌은 높은 위험으로 남기며 기록 순서의 마지막 사용 가능 값을 표시한다. 반려하면 해당 사실만 검색에서 제외하고 남은 근거로 상태를 다시 계산한다. 새 원문·새 분석 revision은 별도 항목이므로 이전 결정이 다른 사실에 적용되지 않는다.

## 검증 수준과 위험도

| 분류 | 의미 |
| --- | --- |
| 원문·저장·범위 검증 | 인용·저장 레코드·현재 범위를 확인했다. 별도의 의미 판단을 보증하지 않는다. |
| 상태 규칙 검증 | 위 조건에 더해 기존 상태 승인 규칙을 통과했다. |
| 추가 검증 미완 | 출처는 확인했지만 동일 시점 충돌이나 추가 검증 요구가 남아 있다. 자동 사용하되 위험도를 높게 표시한다. |

위험도는 낮음/중간/높음이며 원래 사유와 함께 보존한다. 사용자 확정은 검토 결정을 저장할 뿐 검증 수준이나 위험도를 낮추지 않는다.

## 사용자 경로

열람대와 기억 관리 도구 및 Micro 상태 상세에서 **기억·상태 자동 반영 검토**를 연다. 위험도·검증 수준·기억 종류·검토 상태로 분류하고 원문을 펼쳐 볼 수 있다. 선택 확정, 선택 반려, 자동 반영으로 되돌리기를 제공한다. 검증 미완 자료는 자동 사용 후보와 구분한다.

결정은 `libra.memory_review.v1`로 scope 및 논리 세계선별 별도 키에 저장한다. preview/source revision 검증, 로컬 직렬화와 물리 readback을 사용하고 서버 단독/기존 mirror에서는 조건부 batch를 사용한다. 그래프의 프레임·소스 의존성에 결정 레코드를 포함해 기존 검색 결과를 재사용하지 않으며, 최종 상태 읽기에도 물리 근거를 바인딩한다. 결정이 없을 때의 자동 사용은 저장 쓰기를 발생시키지 않는다.

## 실행 검증

- `libra_memory_review_runtime_test.cjs`: Micro 충돌 자동 반영, 높은 위험, 선택 확정/반려/복원, 오래된 preview 거절, 재시작 유지, 반려한 claim의 검색 제외, 원문 수정 거절, 추가 모델 호출 없음.
- `libra_canonical_memory_review_runtime_test.cjs`: 정본 충돌 자동 반영, 반려 사실의 최종 검증된 검색 결과 제외, 정본/Head 바이트 보존, 재구축 유지.
- `libra_memory_review_3mode_test.cjs`: 로컬·기존 mirror·서버 단독에서 저장·반려·확정·재구축. 그래프 소비는 지원되는 로컬/서버 모드에서 검증하며 기존 mirror 그래프 거절 계약은 유지한다.
- `browser/libra_memory_review_browser_test.cjs`: 생산 UI 진입, 검증 수준/위험도/상태 필터, 선택 확정·반려·복원과 320/390px 배치.

호스트와 모델 출력은 합성이며 실제 RisuAI/외부 제공자 검증이나 전체 릴리스 검증은 포함하지 않는다.
