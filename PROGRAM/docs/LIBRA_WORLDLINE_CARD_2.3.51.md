# LIBRA 2.3.51 — 열람대 세계선 카드

열람대의 공용 진단 박스를 LIBRA 전용 세계선 카드로 교체했습니다. 갈색 바탕, 금빛 책갈피 장식, 작은 상태 배지와 접이식 기록을 사용합니다. 일반 채팅에는 불필요한 승계 설명을 표시하지 않습니다.

긴 채팅 ID, 분기 경로, 공통 원문 및 승계 범위, 저장 확인 상태와 진단 코드는 ‘세계선 기록 보기’ 안에서 확인할 수 있습니다. 현재 채팅과 다른 범위의 세계선 정보는 표시하지 않습니다. 텍스트는 DOM textContent로 출력합니다.

공용 Host Lineage SDK, 분기 판단 및 저장 동작은 변경하지 않았습니다. 이전 실패 안내 카드의 표시 수명은 이번 변경 범위에 포함되지 않습니다.

검증: 실제 GUI 함수와 카드 CSS를 사용한 Edge headless 렌더링으로 1100px/360px 레이아웃, 키보드 펼치기, 긴 ID 줄바꿈, 상태별 문구와 다른 채팅 정보 차단을 확인했습니다. 합성 스냅샷을 사용했으며 실제 RisuAI 안의 표시 검증은 수행하지 않았습니다. 관련 회귀 결과와 해시는 review_artifacts/libra_worldline_card_20260908에 기록합니다.
