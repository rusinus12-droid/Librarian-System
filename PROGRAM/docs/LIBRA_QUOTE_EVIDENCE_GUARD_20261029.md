# LIBRA 인용 근거 보정 차단

브랜치: `codex/libra-identity-link-review`, 기준 main `8d89781`. 인용 패치와 사용자 후속 승인에 따른 연결 검토를 같은 별도 브랜치에서 진행했다.

사용자 요청에 따라 관련 LIBRA 변경을 로컬 main에 함께 커밋한다. 원격 푸시는 실행하지 않는다.

사용자가 즉시 패치를 승인한 인용 보정 문제를 수정했다. 글자 편집 거리 12% 이내라는 이유로 인용을 원문 일부로 대체하던 `repairQuoteInSource`와 호출을 제거했다. 부정·수량·행위자가 바뀐 인용을 임의로 고치지 않는다. 기존 근거 검증을 통과하지 못한 인용은 `source_quote_mismatch`로 제외하고, 사실이 거절되면 기존 admission의 State 보류를 유지한다.

정확한 인용, 기존 공백·Unicode 정규화, 원문에 정확히 존재하는 인용의 ref 재연결은 유지했다. 같은 배치에서 검증을 통과한 다른 사실은 계속 저장된다. 인물 자동 연결 검토 변경은 `LIBRA_AUTOMATIC_IDENTITY_REVIEW_20261029.md`에 별도로 기록했다. 과거에 저장된 사실·현재 상태를 자동 변경하는 마이그레이션도 수행하지 않는다.

## 검증

새 `libra_quote_repair_admission_test.cjs`는 수정 전 부정·숫자 반례 2개가 실패했고, 수정 후 4개 모두 통과했다. 실제 생산 분석·입력 검증·저장·Head 경로를 합성 모델 응답으로 실행했다.

- 부정 또는 숫자가 달라 원문에 없는 인용은 거절된다.
- 거절된 사실은 현재 knowledge를 만들지 않으며 State 보류가 기록된다.
- 같은 배치의 정상 위치 사실은 저장된다.
- 정확한 인용과 공백 정규화는 기존대로 통과한다.

집중 회귀 8개 실행 단위 통과: 새 검증 4개, 원문 재분석 부분 prefix 재개, 인물명 경계, 명시적 인물 병합/분리(내부 13개 사례), 자동 점검·복구.
