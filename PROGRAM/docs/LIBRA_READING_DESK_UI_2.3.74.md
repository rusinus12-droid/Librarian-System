# LIBRA 2.3.74 열람대 작업 UI 정리

- 기억 작성 현황의 Librarian 카드에서 AI 프리셋을 직접 선택하고 저장할 수 있습니다.
- GUI를 다시 열었을 때 저장소에 남아 있는 과거 완료 작업 창은 자동으로 열리지 않습니다. 현재 세션에서 실행 과정을 본 작업의 완료 결과는 계속 확인할 수 있습니다.
- 에이전트 작업대는 `기억 작성`과 `LIBRA 응답` 또는 `GRADIA 초안`만 표시합니다. 상태 추적 기능과 기록은 삭제하지 않았으며 설정실의 `상태 추적`과 실행 기록에서 계속 확인할 수 있습니다.

검증 범위는 격리된 Chromium의 전체 플러그인 UI와 로컬 계약 테스트입니다. 실제 RisuAI 설치 환경과 외부 AI 제공자 호출은 이 검증에 포함되지 않습니다.
