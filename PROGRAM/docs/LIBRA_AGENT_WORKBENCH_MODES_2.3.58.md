# LIBRA 2.3.58 에이전트 작업대 모드 표시 수정

설정실의 에이전트 작업대에 남아 있던 `Classic`과 `Planner` 표시를 빠른 설정의 최신 명칭과 맞췄습니다.

- `Classic`은 `사서 모드`로 표시합니다.
- `Planner`는 `플래너 모드`로 표시합니다.
- `Classic · Planner` 탭은 `사서 · 플래너 모드`로 표시합니다.
- 보라색 모드 카드를 책상형 GUI의 종이색·황갈색 팔레트로 변경했습니다.
- 내부 저장값 `classic`과 `planner`는 그대로 유지하여 기존 설정과 호환됩니다.
