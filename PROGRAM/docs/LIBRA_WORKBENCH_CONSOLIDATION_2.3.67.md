# LIBRA 2.3.67 에이전트 작업대 통합

실제 배포 원본 plugins/LIBRA.js에 적용되었습니다. 빠른 설정의 LIBRA가 사서/플래너 모드와 플래너 연결·출력·전달 정책을 담당합니다. 모드 선택이 먼저 표시되고 사서 모드에서는 플래너 전용 설정을 숨깁니다. 기억 Agent가 기억 분석 AI와 정본 분석 요청 한도를 담당합니다.

사이드바 에이전트 상세를 제거하고 프롬프트/OOC 고급 편집을 작업대에 통합했습니다. 작업대의 기존 기본 설정 편집은 현재 설정 요약과 빠른 설정 바로가기로 바꿨습니다. 이전 agents/custom 링크의 선택 위치와 미저장 변경사항을 유지하며 설정실로 이동하면 빠른 설정 오버레이가 닫힙니다. 사이드바 선택 표시도 즉시 동기화됩니다.

2.3.66의 사서 모드 기본값, 명시적으로 저장한 플래너 선택, 데이터와 AI 호출 경로는 유지됩니다. 실행 중인 RisuAI의 설치본은 이 배포 파일로 업데이트해야 새 GUI를 사용합니다.

검증: 배포 파일 문법, 플러그인 로딩, UI/탐색 회귀 검사, 실제 Chromium DOM에서 16개 검사 통과. 모델 요청 없이 미저장 상태 보존과 저장 후 설정 재로드, 데스크톱/모바일 폭을 확인했습니다. Chromium의 외부 호스트 및 저장소는 테스트 대역이며 사용자 RisuAI 설치본을 직접 변경하거나 검증한 것은 아닙니다.
