# LIBRA 2.3.76 — 인물의 목적을 행동으로 연결

플래너와 GRADIA 초안에 Erosync의 목표·접근 방법·다음 행동 구분을 선별 적용했습니다.

- 플래너: 인물의 즉각적인 목적 → 현재 기회·압력 → 가능한 접근 방법 → 이번 응답의 행동을 연결합니다. 사용자 입력에 대한 반응 외에도 인물 자신의 목적에서 출발하는 선택을 검토합니다.
- 초안: 선택을 인물다운 대사·행동·의미 있는 자제로 표현합니다. 거절·보류·접근 변경·목표 포기도 가능한 선택입니다.
- AIDE와 최종 전달: 타당한 능동적 행동을 보존하며, 의도·시도·실제 결과를 구분합니다. RP의 사용자 캐릭터 선택과 소설 모드의 작가 지정·유보 사항을 보존합니다.
- 기존 호출 내부의 프롬프트 변경입니다. 별도 목표 저장, 확률 엔진, 추가 분석 호출, 정본 저장 규칙 변경은 없습니다. 계획은 이미 일어난 사실의 증거가 아닙니다.

검증: 문법 검사와 관련 회귀 검사 10개 통과. RP·소설 × 경량·중량 네 조합의 실제 프롬프트 조립과 모의 제공자 전달을 확인했습니다. 기존 4회·8회 호출 수와 모의 초안 보존을 확인했습니다. 실제 모델의 문체·행동 개선과 RisuAI 실행은 미검증입니다.

추가 버전 검사에서 호출 예산(`libra_232_reader_evidence_governor_contract_test`)과 공개 화면(`libra_public_brand_internal_contract_test`)의 정적 기대값 불일치가 남았습니다. 이번 능동성 지침 8개를 제거한 비교본에서도 동일하게 재현되었습니다. 이번 패치에서 해당 경로를 변경하거나 검사를 완화하지 않았습니다.
