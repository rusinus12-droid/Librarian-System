# NPC 반응 경향성 설계

2026-11-17 작성. 대상: GRADIA (`Gradia_Continuity` 브랜치).

NPC가 페르소나에게 **어떻게 반응할지의 방향**을 유저가 고정하는 기능이다. 반응의 방향은 경향성이 정하고, 반응의 표현 방식은 그 인물의 로어가 정한다.

## 1. 해결하려는 문제

AI는 NPC를 로어에 적힌 기본 태도(대개 호의적인 쪽)로 되돌리는 편향이 있다. 페르소나가 꽃을 건네면 로어상 냉정한 인물도 결국 받아 주고, 적대적이어야 할 인물도 페르소나의 친절에 누그러진다. 유저가 의도한 편향(긍정이든 부정이든)을 확실하게 강제할 장치가 없었다.

예: 페르소나가 NPC에게 꽃을 준다. NPC의 경향성이 '적대'라면, 로어에 따라 경멸하거나 무시하거나 꽃을 빼앗아 짓밟거나 쓰레기통에 버리는 식의 **적극적이고 눈에 보이는 행동**으로 나와야 한다.

## 2. 확정된 결정 (2026-11-17, 사용자)

| 항목 | 결정 |
|---|---|
| 단계 | 적대 · 비호감 · 아는 사이 · 호감 · 애정 (5단계) |

| 지정 단위 | 채팅별. 모든 NPC 기본값 + NPC별 지정 |

## 3. 개념

- **고정되는 것:** 페르소나를 향한 NPC 태도의 방향과 세기. 친절, 선물, 사과, 칭찬, 외모, 평온한 장면이 적대·비호감 NPC를 누그러뜨리지 않고, 무례가 애정 NPC를 식게 하지 않는다.
- **로어가 정하는 것(작성 절차):** 성격, 말투, 습관, 가치관, 사회적 위치, 능력과 수단은 로어 그대로 두고, 아래 순서로 반응을 만든다.
  1. 로어에서 이 인물이 그런 감정의 상대를 어떻게 대하는지 찾는다(쓸 수 있는 수단, 지키는 가치·자존심, 말버릇, 사회적 위치).
  2. 페르소나가 방금 한 행동이 이 인물에게 무슨 의미인지 판단한다.
  3. 이 인물만 할 법한 구체적 반응을 경향성의 방향과 세기에 맞춰 만든다.
- **상투적 반응 금지:** 로어가 가리키지 않는 한 흔한 몸짓(빼앗기, 버리기, 짓밟기, 비웃기, 얼굴 붉히기, 말 더듬기 등)을 쓰지 않는다. 같은 경향성의 두 NPC가 같은 방식으로 반응하면 안 된다.
- **로어와 충돌할 때:** 로어나 기억이 페르소나에게 다른 태도를 적고 있으면 태도는 경향성을 따른다. 그 이유를 설명하는 과거 사건을 지어내지 않고, 지금의 행동으로만 보여 준다(유저 메모가 이유를 주면 그것을 쓴다). 관계의 사실(가족, 배우자, 신분, 함께한 과거)과 호칭은 정사 잠금대로 두고, 그 안의 태도만 바뀐다.
- **적극성:** 페르소나가 경향성이 있는 NPC에게 말을 걸거나, 다가가거나, 만지거나, 무언가를 주거나 부탁하면, 그 NPC는 경향성이 분명히 드러나는 구체적 행동이나 대사를 적어도 하나 보인다. 적대와 애정은 강한 극이고, 비호감과 호감은 분명하되 절제되고, 아는 사이는 의도적인 중립이다. 속마음에만 감추지 않는다.
- **범위:** 페르소나를 향한 태도만 다룬다. NPC끼리의 관계는 로어와 이야기를 따른다. 경향성도 기본값도 없는 NPC는 로어를 따른다.
- **우선순위:** 현재 입력이나 현재 채팅 작가 노트가 특정 NPC의 이번 반응을 명시하면 그 턴에만 그것이 이긴다.

### 3.1 단계 정의 (프롬프트 요지: 방향과 세기만 고정)

| 단계 | 방향과 세기 |
|---|---|
| 적대 `hostile` | 강한 극 — 페르소나가 작아지거나, 사라지거나, 지기를 바란다. 호의를 위협·조종·모욕으로 읽으며 무관심하거나 누그러지지 않는다 |
| 비호감 `dislike` | 절제된 부정 — 거리와 최소 접촉을 원한다. 접근을 반갑지 않은 침입으로 보며, 공개적 공격으로 번지지 않되 분명하고 절제되게 거리를 둔다 |
| 아는 사이 `acquaintance` | 중립 — 가까이하려 하지도, 피하려 하지도 않는다. 현재의 사회적·실무적 틀 안에서만 대하며 특별한 호의나 적의, 친밀한 해석이 없다 |
| 호감 `like` | 절제된 긍정 — 반기고 호의적으로 기운다. 접근을 선의로 받아들이고 기뻐하며, 분명하되 절제되어 있다 |
| 애정 `affection` | 강한 극 — 깊이 애착하며 페르소나가 안전하고 가깝고 잘되기를 바란다. 페르소나의 접근이 큰 무게로 다가와 감정 전체로 맞는다 |

## 4. 구현 위치

모델 호출은 늘리지 않는다. 판독이나 제안이 없는 고정 설정이므로 확장 AIDE로 만들지 않고, 관계 정사 잠금처럼 **모든 초안 단계에 붙는 지침 블록**과 **최종 단계의 짧은 보존 가드**로 넣는다.

| 무엇 | 위치 |
|---|---|
| 단계 정의·정규화 | `NPC_DISPOSITION_LEVELS`, `normalizeNpcDispositionMap` (억결 카드 정의 바로 뒤) |
| 단계 지침 블록 | `npcDispositionStageBlock` — `extensionAideStageBlocks`가 SHADOW·인물·세계관·플롯 모든 초안 단계(작성·분석·패치)에 붙인다 |
| 최종 보존 가드 | `npcDispositionFinalGuard` — 소설 최종·RP 최종 주입의 hard constraint. 다듬는 과정에서 로어 기본 태도로 되돌리지 않게 한다 |
| 설정 키 | `npc_disposition` (JSON: `{ [채팅 키]: { default, npcs: [{ id, name, level, note }] } }`) |
| GUI | 인물 AIDE 상세 패널의 'NPC 반응 경향성' (모든 NPC 기본값 선택 + NPC별 행 추가·삭제, 메모 선택) |

### 4.1 단계별 의무

| 단계 | 의무 |
|---|---|
| SHADOW | 페르소나와 마주치는 NPC의 반응을 위 로어 작성 절차에 따라 경향성의 방향·세기로 쓴다 |
| 인물 AIDE | 반응이 로어 기본 태도·평범한 예의·허용되지 않은 온기(또는 냉기)로 미끄러졌으면 경향성의 방향과 세기에 맞게 고친다. 누구에게나 쓸 수 있는 일반적·상투적 반응이면 그 인물의 로어(수단, 가치관, 말투, 위치)에서 직접 나온 반응으로 고친다. 형식이 로어를 깨면 경향성은 두고 형식만 바꾼다 |
| 세계관 AIDE | 태도가 드러나는 형식이 장소·목격자·사회 규칙·인물의 수단에 맞는지 본다. 형식만 고치고 방향과 세기는 약하게 하지 않는다 |
| 플롯 AIDE | 이번 턴 안에 경향성이 누그러지거나 뒤집히거나 '설득'되지 않았는지, NPC의 태도가 장면을 닫지 않고 페르소나의 다음 행동에 걸리는 당김으로 남는지 본다 |

## 5. 작성 모드별 동작

| 모드 | 동작 |
|---|---|
| 소설 | NPC 쪽에만 적용. 페르소나의 감정과 선택은 작가 지시를 따른다 |
| RP 페르소나 전용 | NPC 쪽만 새 행동·대사·반응을 얻는다. 페르소나의 반응은 쓰지 않는다. 물건·말·사회적 행동은 로어와 경향성에 따라 끝까지 일어나고, 페르소나 몸에 대한 행동은 시작될 수 있지만 그 결과는 기존 RP 접촉 규칙대로 유저에게 남긴다 |
| RP 장면 연출 | 새 행동을 지어내지 않는다. 입력에 적힌 NPC 행동의 표정·몸짓·어조·타이밍만 로어와 경향성에 맞게 연출하며 상투적 몸짓을 빌려 쓰지 않는다 |
| RP 문장화 | 적용하지 않는다 |

## 6. 테스트

`PROGRAM/tests/gradia_npc_disposition_test.cjs` (두 릴리스 워크플로에 등록)

- 설정이 없으면 블록이 어디에도 없고 호출 수가 같다.
- 설정하면 SHADOW·인물·세계관·플롯 모두에 블록, 쓰인 단계 정의만, NPC별 행(장면에 있음·유저 메모), 기본값이 덮는 장면 인물, 단계별 의무가 실리고 호출이 늘지 않는다.
- 최종 주입에 보존 가드가 실린다. 설정이 없으면 없다.
- 소설·장면 연출·문장화 모드 분기.
- 다른 채팅의 설정은 적용되지 않고, 기본값만으로도 동작하며, 한국어 단계 이름('애정')도 받는다. 이름이나 단계가 빈 행은 쓰지 않는다.
- 억결과 함께 켜면 '경향성이 방향, 억결은 긴장만' 규칙이 실린다.
- 인물 AIDE 패널에서 기본값과 NPC별 경향성을 편집·저장·삭제하고, 현재 채팅 키에만 저장된다.

## 7. 남은 판단

- 실행 결과 화면에 이번 턴에 적용된 경향성을 표시할지(현재는 프롬프트 미리보기로만 확인).
- 페르소나별(LIA 페르소나 전환) 경향성이 필요한지. 지금은 채팅 단위다.
- 실제 대화에서 적대 단계의 행동 강도가 과하거나 약하면 단계 문구를 조정한다.
