# 정사 AIDE 설계

2026-11-18 작성. 대상: GRADIA 확장 AIDE `aide_intimacy`(화면 이름 '정사 AIDE'). 상태: 구현.

장면이 성교에 들어선 뒤 전희·성교·절정·후희를 단계별로 구체적이고 정확하게 묘사하게 하고, 인물마다 로어로 추정한 성적 선호를 따르게 한다.

## 1. 확정된 결정 (2026-11-18, 사용자)

| 항목 | 결정 |
|---|---|
| 위치 | 인물 AIDE의 하위 AIDE. 별도 호출 없이 인물 AIDE 호출 안에서 판독을 정한다 |
| 역할 | 성교에 진입한 뒤의 묘사 보조. 성교를 시작시키지 않는다 |
| 참고 지식 | 사용자가 준 백과사전 자료(단계·체위·해부학·오르가즘·여성 사정)를 GRADIA 집필에 필요한 것만 남겨 재작성. 수치·연구·호르몬명 같은 서술에 쓰이지 않는 내용은 뺀다 |
| 인물 선호 | 좋아하는·싫어하는 체위, 전희·성교·후희 각각의 선호(좋아함/보통/싫어함/모름)와 진행 방식·좋고 싫은 방식을 로어로 추정 |
| 선호 저장 | 채팅별로 저장한다. 한 번 만들어진 기록은 카드로 남는다 |

## 2. 설계 결정 (구현 시 정함)

| 항목 | 결정 | 이유 |
|---|---|---|
| 기본값 | 꺼짐 | 다른 확장 AIDE와 같음 |
| NSFW 연동 | NSFW 지침이 켜져 있고 모드가 OFF가 아닐 때만 실행. 어휘 수위는 NSFW 모드(SOFT/DIRECT/EXPLICIT)를 따른다 | 수위 결정을 한곳(NSFW 설정)에 두고, NSFW를 끈 사용자에게 노골 묘사가 새지 않게 |
| 실행 순서 | `rank` 15: 세계 동역학(5) → 상태(10) → **정사(15)** → 억결(20) | 부상·임신 같은 몸 상태가 행위 안에서도 적용되어야 하므로 상태 다음 |
| 작성 모드 | 소설: 모든 참여자 서술. RP 페르소나 전용: 페르소나의 행동·감각·절정·선호는 입력에 적힌 것만. 장면 연출: 새 행위·체위·절정 없이 적힌 행위만 묘사. 문장화: 실행 안 함 | 억결·상태 AIDE와 같은 모드 규칙 |
| 카드 저장 위치 | 전용 저장 키 `serial_gradation_agents_for_rp:intimacy_cards:v1` (`{ version, savedAt, cards: { 채팅 키: [카드] } }`) | 실행 중 자동 생성된 카드를, 열려 있던 설정 창의 저장이 덮어쓰지 않도록 런타임 설정과 분리 |
| 카드 덮어쓰기 | 자동으로는 절대 바꾸지 않음. 같은 이름의 새 추정은 버린다. 사용자는 패널에서 고치거나 지운다(바로 저장) | "한 번 만들어진 기록은 카드로 남긴다" |
| 카드 상한 | 채팅마다 12장 | |

## 3. 매 턴 패킷 (모델 호출 없음)

코드가 현재 입력과 최근 장면(완료된 최근 4개 메시지)에서 계산한다. 저장하지 않는다.

- **단계:** 입력에 행위 신호가 있으면 입력이 우선(절정 뒤 "다시 삽입"은 2회전 성교). 없으면 행위가 보이는 가장 최근 메시지. 한 텍스트 안에서는 가장 뒤 단계(전희 < 성교 < 절정 < 후희)
- **진입 판정:** 키스·옷 벗기만으로는 진입이 아니다. 애무·성기 접촉·삽입·절정 같은 행위 신호가 있어야 한다. "여운", "숨을 고르다" 같은 후희 단어는 같은 텍스트에 행위가 있을 때만 후희로 읽는다
- **끝난 장면:** 입력에 신호가 없고 마지막 신호가 두 메시지보다 더 전이면 끝난 것으로 본다
- **체위:** 마지막으로 언급된 체위(정상위·기승위·후배위·측위·굴곡위·신장위·교차위·대면/후면 좌위·대면/후면 입위·69)
- **선호 카드:** 이 채팅의 저장된 카드 전부

진입하지 않은 턴에는 한 줄("진행 중인 성교 없음, 시작시키지 않음")과 빈 배열 출력 요청만 붙는다.

## 4. 단계별 역할

| 단계 | 역할 |
|---|---|
| SHADOW | 현재 단계를 요약하지 않고 박자 단위로(접촉·압력·리듬·마찰·호흡·소리·젖음·목소리) 쓴다. 입력이 더 나가지 않는 한 한 턴에 한 단계까지만 전진 |
| 인물 AIDE(호스트) | 자기 점검 + 정사 판독 확정: 단계·체위·참여자별 상태(`intimacy_readings`), 카드 없는 참여자의 선호 추정(`intimacy_profiles`), 요약·생략·해부학 오류·체위 불연속·선호 위반만 패치 |
| 세계관 AIDE | 체위가 이 몸과 장소에서 가능한지, 옷·자세·접촉·체액이 이어지는지 |
| 플롯 AIDE | 단계 속도: 절정으로 건너뛰기, 이른 후희, 입력이 열어 둔 행위를 닫는 결말 금지 |

검증 메모(`intimacy_check`)는 호스트보다 먼저 실행되는 단계만 남긴다(SHADOW, 그리고 사용자가 인물 AIDE 앞에 둔 핵심 AIDE). 호스트 뒤에 실행되는 단계는 자기 역할 지침만 받는다.

인물 AIDE가 꺼져 있으면 실행되는 마지막 핵심 AIDE가 호스트를 맡고, 핵심 AIDE가 모두 꺼졌을 때만 단독 단계로 실행된다(확장 AIDE 공통 틀).

## 5. 참고 지식 (단계별로 필요한 것만 첨부)

| 현재 단계 | 첨부 |
|---|---|
| 전희 | 흐름 + 전희 |
| 성교 | 흐름 + 성교 + 전희 |
| 절정 | 흐름 + 절정 + 성교 |
| 후희 | 흐름 + 후희 + 절정 |

각 줄은 장면에서 보여 줄 수 있는 사실로만 쓴다(예: "젖음은 흥분으로 생기며 즉시 생기지 않는다", "체위 전환은 몸을 움직이는 과정으로 보여 준다", "사정 후 남성은 회복 시간이 필요하다").

## 6. 선호 카드

| 필드 | 내용 |
|---|---|
| `name` | 인물 이름 |
| `likedPositions` / `dislikedPositions` | 좋아하는·싫어하는 체위 |
| `foreplayStance` / `intercourseStance` / `afterplayStance` | likes · neutral · dislikes · unknown |
| `foreplayStyle` / `intercourseStyle` / `afterplayStyle` | 그 단계를 어떻게 이끌거나 따르는지, 어떤 방식을 좋아하고 싫어하는지 |
| `basis` | 추정 근거(로어) |
| `origin` | `lore`(자동 추정) 또는 `user`(직접 작성·수정) |

- 호스트는 카드가 없는 참여자에 대해서만 `intimacy_profiles`를 낸다. 근거는 캐릭터 카드·로어북·기억 증거이고, 로어가 말하지 않으면 성격에서 추정했다고 `basis`에 적는다.
- RP 모드에서는 페르소나 카드를 만들지 않는다(프롬프트로 지시하고 코드에서도 거른다).
- 카드는 장면에서 확정된 인물 사실로 다룬다. 싫어하는 것도 장면에 이유가 있으면 할 수 있지만, 그때는 망설임이나 예외로 보여 준다.

## 7. GUI

정사 AIDE 패널(인물 AIDE 하위 · 같은 호출에서 실행):
- 사용 스위치(`on-s8`), 단독 실행 설정
- **이 채팅의 선호 카드:** 카드별 편집(인물, 출처, 좋아하는·싫어하는 체위, 전희·성교·후희 선호와 방식, 근거), 카드 삭제, 카드 추가. 바뀌면 바로 저장되고 출처가 '직접 작성·수정'이 된다
- **이번 턴 판독:** 참여자 · 단계 · 체위 · 한 줄 요약(메모리에만)
- 창작 지침, 프롬프트 미리보기, 실행 결과(결과 탭 '정사', 인물 탭 바로 뒤)
