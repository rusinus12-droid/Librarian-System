# GRADIA 설정 화면: 적용 범위별 배치

2026-11-18 작성. 상태: 1·2·3단계 구현.

## 문제

설정이 초안 파이프라인의 단계 패널에 흩어져 있었다. 그중 상당수는 특정 단계의 설정이 아니다.

| 설정 | 이전 위치 | 실제 범위 |
|---|---|---|
| NPC 반응 경향성 (모든 NPC 기본값 포함) | 인물 AIDE 패널 | 이 채팅 · 모든 단계와 마무리 |
| 관계 카드·AI 제안 (억결) | 억결 AIDE 패널 | 이 채팅 |
| 상태 카드 | 상태 AIDE 패널 | 이 채팅 |
| 정사 선호 카드 | 정사 AIDE 패널 | 이 채팅 |
| 이번 턴 판독 (상태·세계 동역학·정사) | 각 하위 AIDE 패널 | 이 채팅의 최근 실행 |
| 장면 변수 | SHADOW ACT 패널 | 모든 채팅 · 모든 단계 |
| 성인 장면 표현·NSFW 지침·최종 요청 전달·비앙카 | 메인 응답 › 응답 옵션 | 모든 채팅 · 모든 단계 (정사 AIDE 실행 조건) |
| RP 세부 모드 | 상단 바 (RP일 때만 보임) | 모든 채팅 · 모든 단계 |

## 1단계 (구현)

- **작성 방식** 페이지(`data-page="writing"`, 칩 `모든 채팅`): RP 세부 모드, 장면 변수, 성인 장면(표현 수준·NSFW 지침·최종 요청 전달·비앙카).
  - RP 세부 모드는 상단 바에도 그대로 있다. 이 페이지에서는 소설 모드일 때 비활성으로 보이고 이유를 적는다.
- **이 채팅** 페이지(`data-page="chat"`, 칩 `이 채팅`): NPC 반응 경향성, 관계 카드·AI 제안, 상태 카드, 정사 선호 카드, 이번 턴 판독 세 가지. 머리에 현재 채팅(캐릭터 이름)을 보여 준다.
- 단계 패널에는 원래 자리에 안내 한 줄과 **이 채팅 열기** / **작성 방식 열기** 버튼을 남긴다. 버튼은 해당 페이지의 해당 구역(`data-go-sub`)으로 이동해 잠깐 강조한다.
- 단계 패널 제목에는 `이 단계` 칩을 붙인다.
- 단계에 속하는 설정(사용 여부, 프리셋, 한도, 참고 자료, 창작 지침)과 하위 AIDE의 동작 스위치(억결 자동 엮기·등장 계기, 상태 생식 판정)는 단계 패널에 남는다.

저장 구조는 바뀌지 않았다. 입력 요소의 `data-*` 식별자를 그대로 옮겨 기존 렌더와 이벤트 처리 코드가 그대로 동작한다.

## 2단계 (구현)

- **설정 검색:** 상단 바의 `설정 검색` 버튼, Ctrl/⌘+K, 또는 입력 칸 밖에서 `/`. 화면의 설정 이름·설명·단계 이름·페이지 이름과 동의어 목록(예: nsfw → 성인 장면, 타임아웃 → 대기 시간, 적대 → NPC 반응 경향성)으로 찾는다. 고르면 그 페이지, 단계 패널, 탭, 접힌 영역을 차례로 열고 그 설정을 가운데로 스크롤해 강조한다. 카드 내용·판독 같은 동적 목록은 검색 대상이 아니다.
- **꺼진 이유와 원인 링크:** 저장 전 화면 값으로 계산해 단계 패널 맨 위에 보여 준다.
  - 작동 방식 꺼짐 → 전체 미실행 (개요로)
  - SHADOW ACT 꺼짐 → 전체 미실행 (SHADOW ACT로)
  - 라이트 모드 → 인물·세계관 AIDE 건너뜀 (개요로)
  - RP 문장화 모드 → 하위 AIDE 미실행 (작성 방식 › 작성 모드로)
  - 성인 장면 OFF 또는 NSFW 지침 꺼짐 → 정사 AIDE 미실행 (작성 방식 › 성인 장면으로)
  - 상위 AIDE가 꺼짐/건너뜀 → 어느 AIDE가 대신 처리하는지 (상위 AIDE로)
  - 핵심 AIDE가 모두 꺼짐 → 하위 AIDE가 단독 단계로 실행되어 호출이 1회 늘어남
  - 이 채팅 페이지의 관계·상태·선호 카드 구역: 해당 AIDE가 꺼져 있으면 "카드가 지금 쓰이지 않음" (그 AIDE로)
- **바꾼 설정:** 관리 · 진단 › `바꾼 설정` 탭(개수 표시). 작동 방식, 작성 모드, RP 세부 모드, 장면 변수, 성인 장면 4항목, 내부 초안 언어, 목표 분량, 빠른 설정 프로필, 인풋 관리자, AIDE 순서, 억결·상태 동작 스위치, 그리고 단계마다 사용·프리셋·최근 대화 수·참고 상한(빠른 설정 프로필 기준)·대기 시간·창작 지침을 기본값과 비교한다. 행마다 `이동`, 되돌릴 수 있는 값은 `기본값으로`(저장해야 적용). 이 채팅의 경향성·카드는 기본값이 없으므로 목록으로만 보인다.

## 3단계 (구현)

- **단계 비교표:** 초안 파이프라인 페이지 맨 위의 접이식 카드. 행은 실행 순서(SHADOW ACT, 사용자가 정한 순서의 핵심 AIDE, 각 핵심 AIDE 바로 아래 하위 AIDE), 열은 사용·AI 프리셋·최근 대화 수·참고 상한·대기 시간·상태.
  - 단계 패널과 같은 `Gui.state.agents` 값을 같은 범위 규칙(대화 1~64턴, 상한 500~60,000자, 대기 1~600초)으로 바꾼다. 숫자는 입력을 마칠 때(change) 반영해 입력 중에 표가 다시 그려지지 않는다.
  - 기본값과 다른 칸은 테두리로 표시한다. 단계 이름을 누르면 그 단계 패널로 간다.
  - 상태 열: 실행 / 꺼짐 / 실행 안 됨(이유) / ○○ 안에서(하위 AIDE의 호스트) / 단독 실행. 이유는 2단계의 꺼진 이유와 같은 계산이다.
  - 하위 AIDE의 프리셋과 한도는 단독 실행 때만 쓰인다고 행에 적는다.
  - **모든 단계에 적용** 줄: 프리셋·대화 수·상한·대기 시간을 한 번에 넣는다. 각 단계의 범위 규칙은 그대로 적용된다.
  - 좁은 화면(앱 폭 900px 이하)에서는 단계마다 카드로 쌓고 값마다 이름을 붙인다.
- 저장 버튼을 눌러야 적용되는 것은 다른 설정과 같다.
