# Librarian System development source

This working tree contains six plugins: LIBRA, HAYAKU, Flashback, LIA, RETRACE and GRADIA.
It is development source, not a qualified release or an installable package.

## Separation on 2026-10-10

The independent World Manager plugin and its source, server, updater, SDK-only,
build and test integrations have been preserved as a separate project before
removal from this tree. The pre-separation source and local Git history are
preserved byte-for-byte. No runtime DATA was altered. LIBRA's own internal
WorldManager remains part of LIBRA; its prompts and state logic were not changed.

The separate project includes the unfinished performance candidate, required
assembly inputs, pinned reference fixtures, tests and retained evidence. Its
known performance/qualification failures remain unresolved. Separation is not
an adoption of that candidate or an extension of LIBRA.

## Layout and builds

- PROGRAM/plugins: six readable Full plugin sources
- PROGRAM/sdk, PROGRAM/server: shared client and server source
- PROGRAM/tests, PROGRAM/docs: tests, fixtures and authored documentation
- PROGRAM/tools: build, synchronization and packaging tools
- PROGRAM/build-support: locked shared parser/minifier/test dependencies
- UPDATER: updater source

Node.js 22.13 or newer with node:sqlite is required. The inspected environment
uses Node.js 24.19.0. Installed dependencies are not included; use the locked
package files in PROGRAM/build-support. Do not replace synthetic golden fixtures
or normalize pinned source bytes. No installation or network access is implicit.

The actual release builder is PROGRAM/tools/build_distribution.cjs. Its source
profile exports readable sources, while its release profile performs the full
mandatory smoke gate and creates six Min plugins. Use a clean package export for
layout checks: a Git checkout includes development-only metadata and is not a
distribution-shaped installation. Generated manifests/checksums bind a specific
staged export and must be regenerated by the existing tools after source changes.

## Qualification and history

Focused separation controls are distinct from full release validation. Actual
Windows/Risu host and real model quality remain unverified. Earlier campaign
failures and partial results are retained; they must not be converted into a
whole-regression pass. Historical release provenance records may name removed
components and describe their past bytes; current component lists contain six.

Local Git commits do not imply remote publication. Runtime DATA, credentials,
logs, installed dependencies and generated artifacts remain outside source Git.
Review staged files before sharing. The new recovered Git history does not
reconstruct the pre-recovery local object history.
