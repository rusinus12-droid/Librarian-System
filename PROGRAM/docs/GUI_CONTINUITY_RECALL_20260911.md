# HAYAKU / Flashback GUI 컨셉 적용

2026-09-11. 대상: HAYAKU 3.0.80, Flashback Memory 1.0.60.

## 구현

- HAYAKU: 청회색 관제실 테마와 중앙 연속성 노선도. 완료 턴 대조 결과를 기반으로 누락·수정 검토 대기·사용자 제외를 구분한다. 원장 기록 사이 숫자 간격만으로 누락을 추정하지 않는다. 노선은 24턴 단위로 탐색하며, 저장된 패킷은 해당 기록으로 이동하고 누락/검토는 기존 복구 화면으로 이동한다. 스코프 변경 시 이전 대조 결과와 페이지를 비운다.
- Flashback: 크림색/차콜 현상실 테마, 최근 검색 장면, 펼칠 수 있는 기억 프레임, 선택 기억 필름 스트립. 본문과 출처/검색 진단을 나누어 제공한다. 실제 cosine이 있는 결과에만 유사도 미터를 표시하며 복합 점수는 원값을 유지한다. 선택을 주입 완료로 오인시키는 도장은 넣지 않았다.
- 기존 설정·연결·복구·백업·로그 화면도 같은 색상과 카드/버튼 체계로 조정했다. 기존 저장/AI 호출/동의 절차와 기능 ID는 유지했다. 모바일에서 헤더 브랜드·채팅 범위·검색 문장이 보이도록 수정하고 제목 말줄임, 중복 펼침 아이콘, 어두운 기존 페이지 배경을 정리했다.

## 시각 검증

작업공간의 `design_samples/continuity-recall/implemented/index.html`에 변경 전 / 컨셉 / 변경 후 스크린샷과 모바일 캡처를 모았다. `build-implemented.cjs`는 실제 소스에서 GUI 쉘과 렌더 함수를 추출하고 가상 데이터를 제공하는 미리보기 생성 도구다. 미리보기 탐색은 별도 어댑터이며 저장과 AI 호출은 연결하지 않는다. 실제 호스트의 모든 이벤트 바인딩을 재현한 실행 환경은 아니다.

데스크톱과 390px 화면을 직접 캡처하여 컨셉과 비교했다. 하야쿠는 기존 60px 헤더 잘림 및 모바일 노선 제목 배치를 수정했다. 플래시백은 기존 어두운 제목 영역, 모바일 브랜드/검색문 숨김, 기억 제목 잘림을 수정했다. 실제 기억 상세에서 본문과 cosine 표시도 확인했다.

## 회귀 검증

- 관련 테스트 파일 30개 통과. 초기 2개 실패는 변경된 마크업 기대값 및 CRLF에 의존한 소스 구간 추출을 갱신한 뒤 재검증했다. 테스트 기능 요구사항은 제거하지 않았다.
- 신규 `continuity_recall_concept_runtime_test.cjs`: 실제 coverage 기반 상태, 24턴 페이지, 안전한 탐색, HTML 이스케이프, 스코프 격리, 선택과 전달 구분, 기존 기능 컨트롤 보존.
- `tools/gui_verify.js`: 135/135 통과.
- 공통 SDK/Compute/HostLineage 동기화 검사 통과. 변경하지 않은 원본 구간의 줄바꿈을 보존하여 내장 SDK의 바이트 차이를 방지했다.
- 결과 로그: 작업공간 `design_samples/continuity-recall/implemented/test-results.json`.

## 범위와 한계

실제 플러그인 소스를 패치했다. 스크린샷은 실제 GUI 렌더러 + 가상 데이터이며, RisuAI 호스트에서 실제 채팅·서버·유료 제공자를 연결한 검증은 수행하지 않았다. 예시의 임의 수동 검색/가상 데이터 조작 기능을 제품 기능으로 추가하지 않았다. Flashback 화면은 기존 엔진이 실제로 반환한 최근 검색 결과를 표시한다. 엔진·저장 정책을 변경하는 작업은 포함하지 않는다.

변경 전 소스 백업: 작업공간 `_backups/continuity-recall-20260911/`. 배포 manifest와 SHA256SUMS는 최종 소스 기준으로 재생성한다.
