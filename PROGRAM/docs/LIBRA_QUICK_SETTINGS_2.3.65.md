# LIBRA 2.3.65 — 빠른 설정 정리

빠른 설정은 응답 방식, Input Writer, 기억 Agent에 집중합니다. AI 연결, 임베딩 연결, 서버 연결은 중복된 편집 화면을 만들지 않고 LIBRA 설정 사이드바의 전용 페이지에서 관리합니다.

기존에 저장된 빠른 설정 선택값이 `ai`, `embedding`, `server`였던 경우에는 응답 탭으로 안전하게 정규화합니다. 연결 설정과 저장된 프리셋은 변경하지 않습니다.

검증 범위: 빠른 설정 DOM 렌더링, 오래된 선택값의 응답 탭 폴백, 사이드바 연결 화면의 독립 접근. 실제 RisuAI 호스트와 외부 프로바이더 호출은 이 문서의 검증 범위에 포함하지 않습니다.
