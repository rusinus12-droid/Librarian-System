# HAYAKU 3.0.106 — 문제 항목만 표시하는 구간 점검

- 원문 수정 동기화에서 `applied`·`superseded` 이력을 숨긴다. 승인·확인·재시도·처리가 필요한 항목만 표시한다. 저장된 이력은 삭제하지 않는다.
- 문제가 없으면 “확인할 원문 수정이 없습니다”를 표시하고 확인 버튼을 숨긴다. 과거 “응답 버전 전환”, “대기”, 전체 이력 건수를 나열하지 않는다.
- 수동 복구에서는 `missing` 턴만 표시한다. 정상 턴, 사용자 제외 턴, 별도 원문 수정 확인 대상은 나열하지 않는다. 정상으로 바뀐 턴이나 원문이 바뀐 턴의 기존 선택은 해제한다.
- 누락이 없으면 “복구할 누락 턴이 없습니다”만 표시하고 선택·복구 버튼을 숨긴다. 복구가 차단된 누락은 상태를 표시하되 실행을 허용하지 않는다. Cold Start 대상은 해당 경로로 안내한다.
- 조회 불가·조회 오류·원문 수정 상태 읽기 오류는 문제 없음으로 취급하지 않는다. 이전 선택을 제거하고 오류와 다시 확인 버튼을 표시한다.
- “미처리 수정 없음” 결과만으로 삽화가 원인이었다고 단정하던 안내를 제거한다.

관련 회귀 스크립트 38개가 통과했다. 새 UI 회귀 검사는 생산 렌더 함수를 격리 실행해 정상·누락·수정 대기 혼합 목록, 빈 목록, 선택 정리, 오류 전환, 다른 스코프 상태를 검증한다. 실제 브라우저 스크린샷 검증은 수행하지 않았다. 복구 엔진·원장·승인 규칙·데이터 보존 정책은 변경하지 않았다.
