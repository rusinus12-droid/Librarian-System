# Flashback 서버 설정 색상

서버 설정 패널은 Flashback 전체 GUI의 `surface`, `surface2`, `text`, `text2`, `accent` 변수를 사용한다. 종이색 배경, 차콜 제목·본문, 갈색 설명, 벽돌색 선택·적용 버튼으로 통일한다. 정상·경고·실패 상태는 기존 Flashback 상태 색상 변수를 따른다.

공용 SDK의 기본 남색 배경·흰 글자·파란 버튼을 Flashback 호스트 내부 CSS에서 재정의한다. 상단바용 `.scope` 규칙이 현재 스코프를 가리거나 모바일에서 숨기지 않도록 서버 패널 안에서 구분한다. 선택된 전역 범위의 설명도 배경에서 충분히 읽히는 강조 글자색을 사용한다.

Storage SDK, 모드 전환·이전·복원·확인 로직과 다른 플러그인의 테마는 변경하지 않는다.

`tests/browser/flashback_server_theme_browser_test.py`는 실제 전체 플러그인을 합성 호스트에서 실행해 데스크탑·태블릿·모바일·가로 화면의 색상 일치, 본문·제목·범위 설명의 4.5:1 이상 대비, 입력·버튼 접근성, 모드 선택·주소 편집과 이전 확인·취소를 검사한다. LLM과 실제 백엔드 호출은 없다.
