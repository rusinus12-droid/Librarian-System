# 사용성 개선 1단계: 설정 간소화와 데이터 표기 (2026-10-15)

LIBRA · HAYAKU · Flashback · GRADIA 네 플러그인에 공통으로 적용한 첫 번째 사용성 정리입니다.
저장 형식, ARG 이름, 기본값, 저장·검증·롤백 트랜잭션은 바꾸지 않았습니다. 화면 표시만 바뀝니다.

## 설정 간소화

### HAYAKU — 설정 화면 `간편 / 전체` 보기

- 설정 화면 상단에 **보기 방식** 전환(간편 · 전체)을 추가했습니다. 기본값은 간편입니다.
- 간편 보기에서는 자주 바꾸는 9개 항목만 보입니다.
  - 기본 동작: HAYAKU 사용, 성능 모드, 패킷 출력 위치, 기억 언어
  - 기억 선택: 문맥 메시지 수
  - 복구 · 안전: 패킷 복구, afterRequest 자동 복구, 백그라운드 자동 복구, Cold Start 묶음
- 숨겨진 항목은 섹션마다 "세부 조정 항목 N개가 숨겨져 있습니다 · 전체 보기" 안내로 표시합니다.
- 간편 보기에서는 `hayaku_*` 인자 이름표를 숨깁니다. 전체 보기에서는 그대로 보입니다.
- 설정 검색에 글자를 입력하면 보기 방식과 관계없이 모든 항목에서 찾습니다.
- 선택한 보기 방식은 해당 브라우저의 localStorage(`hayaku.settingsView.v1`)에 기억합니다. 저장이 막힌 환경에서는 간편 보기로 시작합니다.
- 숨겨진 컨트롤도 DOM에 남아 있으므로 저장, readback 검증, 기본값 되돌리기는 이전처럼 39개 설정 전체에 적용됩니다.

### 값 표시를 한국어로

HAYAKU 선택지는 저장값(`auto`, `tail`, `source` …)을 그대로 두고, 보이는 글자만 바꿨습니다.

| 설정 | 저장값 → 표시 |
| --- | --- |
| 성능 모드 | auto/fast/balanced/deep → 자동/빠르게/균형/깊게 |
| 프롬프트 방식 | auto/balanced/full → 자동/균형 · 핵심 지시/전체 · 상세 지시 |
| 패킷 출력 위치 | auto/tail/wrapper/footer → 자동 (본문 뒤)/본문 끝/닫는 태그 앞/꼬리말 영역 |
| 프롬프트 캐시 | off/structural/native → 사용 안 함/구조 캐시/제공자 기본 캐시 |
| 기억 언어 | source/ko/en/ja/zh → 대화 원문 언어/한국어/영어/일본어/중국어 |
| 추가 복구 허용량 · Cold Start 묶음 | 숫자 → 추가 호출 없음/1회 추가, 1턴씩/5턴씩/10턴씩 |

"현재 실제 적용" 안내도 같은 표시 이름을 씁니다.

## 데이터 표기

- **Flashback**: 비용이 `$0.000000`처럼 0이 길게 붙던 표기를 `$0`, `<$0.0001`, `$0.0012`, `$0.125`, `$1,234.50` 형태로 바꿨습니다. 0이 아닌 아주 작은 비용은 0으로 보이지 않습니다.
- **Flashback**: 리콜 설정의 스위치 행에서 이름과 설명이 한 줄로 붙어 보이던 문제를 고쳐 두 줄로 나눴습니다.
- **HAYAKU**: 상단 경로의 `0 records`를 `기록 0개`로, 관제 배지의 `coverage N%`/`coverage 미확인`을 `연결률 N%`/`연결률 미확인`으로 바꿨습니다.
- **LIBRA**: 기억 서가 검색창과 `찾기` 버튼이 두 줄로 갈라지던 배치를 한 줄로 맞추고, 목차 하단 `0 / 0 Chapter`를 `0 / 0장 표시`(천 단위 구분), `Chapter 더 보기`를 `다음 장 더 보기`로 바꿨습니다.
- **GRADIA**: AI 연결과 모델 화면에서 편집 카드가 좁은 왼쪽 목록 열 아래로 밀려 입력칸이 잘리던 문제(Provider가 `Custom O…`로 잘림)를 고쳤습니다. 편집 카드는 승인 시안처럼 오른쪽 넓은 열에 표시됩니다.

## 승인 시안과의 관계

승인된 시안 스타일시트(`docs/gui-redesign`) 문자열은 바이트 단위로 그대로 두었습니다.
추가 스타일은 별도 상수(`HAYAKU_SETTINGS_EASY_CSS`, `LIBRA_UX_POLISH_STYLE`)나 Flashback 스타일 문자열의 끝에 붙였습니다.

## 확인한 범위

- 새 테스트 `tests/hayaku_settings_easy_view_test.cjs`: 간편 보기 기본값, 필수 9개 항목, 컨트롤 값 불변, 한국어 표시와 정규 저장값, 보기 방식 기억, 중복 설치 방지.
