# HAYAKU 서버 설정 화면

서버 연결 화면은 전체 GUI의 `surface/text/accent` 및 상태·경고 색상 변수를 따른다. 공용 Storage SDK의 데이터 처리·연결·이전 로직은 유지하며 HAYAKU 화면 안에서 기존 DOM 노드를 저장 범위, 저장 방식, 연결 설정으로 묶는다. 이벤트 핸들러와 확인창 노드를 재생성하지 않는다.

기존 `grid g2`의 빈 오른쪽 열을 제거하고 서버 패널에 전체 내용 폭을 준다. 실제 패널 폭을 기준으로 container query를 적용한다.

- 760px 이상: 저장 방식과 연결 설정을 좌우 배치.
- 480–759px: 두 구역을 세로 배치하고 저장 방식 선택지는 두 열로 표시.
- 480px 미만: 저장 범위, 방식 선택지와 연결 설정을 한 열로 표시. 버튼은 폭에 맞게 줄바꿈.

URL, 버튼, 긴 스코프 ID와 진행·오류 문구는 내용 영역 안에 머물게 한다. 공용 상단바의 `.scope` 표시 규칙이 서버 패널의 현재 스코프를 숨기거나 흐린 색상을 적용하지 않도록 패널 내부에서 구분한다. 스코프 데이터 관리는 별도 메뉴로 유지한다.

`tests/browser/hayaku_server_settings_browser_test.py`는 전체 실제 플러그인을 합성 호스트에서 실행한다. 데스크탑·태블릿·모바일과 가로 화면에서 색상, 배치, 현재 스코프 표시, 제목·설명·범위 힌트·입력·버튼의 실제 배경 대비(4.5:1 이상), 입력·버튼 접근성, 모드 선택과 주소 편집, 이전 동의·취소 및 고급 작업 노출을 확인한다. 실제 백엔드·LLM 요청은 하지 않는다. 기존 전체 이전/복원 GUI 회귀 검사는 실제 서버 핸들러와 SQLite를 사용한다.
