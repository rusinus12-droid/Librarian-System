# LIBRA 2.3.95 인물 카드함

인물 카드함의 소개 페이지를 세계 도감·서사 연감과 같은 종이색 지면과 적갈색 책갈피로 개선했다. 전체 GUI, 저장 구조, 인물 분석/교정 계약은 변경하지 않았다.

- 이름·별칭 색인과 검색 결과 없음 안내. 이름 첫 글자를 표식으로 쓰며 인물 외형을 생성하지 않는다.
- 인물 소개 / 현재 상황 / 관계 / 지식 / 소속·사물의 다섯 분류. 기존 추가 필드는 소개에서 계속 읽을 수 있다.
- 필드별 확인 턴과 인용을 펼쳐 읽는다. 인용이 없으면 미연결로 표시하며 다른 필드의 근거로 대신하지 않는다. 명시적 해제와 교정 표식을 유지한다.
- 관계 방향과 차원을 보존한다. 상대 이름은 ID로 조회하며 상대 인물 카드와 기존 관계 관리로 이동한다. 확실성 미기록을 confirmed로 채우지 않는다.
- locationRef, affiliation organizationRef, world ownerRef/holderRef/managerRef만 세계 연결에 사용한다. 현재/이전 소속, 소유/소지/관리를 구분한다. 연결 ID 없는 서술을 이름 매칭으로 연결하지 않는다.
- 비어 있는 분류는 기록 없음으로 표시한다. 지식 미기록을 무지로 추정하지 않는다.

근거 표식은 짙은 적갈색(#70443e)과 옅은 배경(#eee0d5)을 사용하며 실제 계산된 글자 대비를 6:1 이상으로 확인했다.

## 검증

전체 운영 소스를 통제된 RisuAI 호스트와 모델 응답으로 실행한 Chromium 검사 41개 통과. 정본 분석·저장, 기존 프로필 필드/레거시 보존, 항목 근거, 양방향 관계, 상대 인물/세계 이동, 별칭 검색, 빈 기록, 1440/1024/390px, State 불변성과 정본 저장 보존을 확인했다.

세계 도감 28개, 서사 연감 24개 브라우저 회귀 검사 통과. 인물 프로필 런타임 9개 시나리오(교정/재생/재시작과 로컬 HTTP/SQLite 포함) 통과. character_info provider 계약 검사의 기존 프롬프트 길이 상한(11,200자) 검사는 변경 전 원본에서도 동일하게 실패했으며, 이번 GUI 작업에서는 프롬프트를 변경하지 않았다.

736/390px에서 승인 시안과 실제 페이지 렌더링을 촬영·비교했다. 전체 LIBRA 조작 화면과 독립 페이지 캡처는 `review_artifacts/libra_character_cabinet_20260912`에 있다. 모든 비교 데이터는 가상이며 실제 사용자의 RisuAI 세션/실제 모델 검증은 수행하지 않았다.
