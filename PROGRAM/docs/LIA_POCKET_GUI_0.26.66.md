# LIA Pocket Studio 시각 재설계 — 0.26.66

예시와 0.26.65 실제 렌더러를 414×896에서 캡처해 비교했다. 이전 적용은 프로필·행동 카드가 크고, 긴 설정 폼과 상태줄이 처음부터 노출되어 예시의 휴대폰 앱 구성과 차이가 컸다.

## 수정

- 기본 창을 휴대폰 비율로 줄이고 메뉴에서 넓은 화면을 선택하도록 했다. 넓은 화면은 홈을 2열로 표시한다.
- 예시의 프로필 비율, 선형 SVG 아이콘, 작은 상태 카드, 하단 메뉴, 여백과 색상을 적용했다. 가상 Persona 사진 대신 중립적인 실루엣을 사용한다.
- 홈 Live Sync 스위치는 기존 설정·중지 함수와 저장 검증을 사용한다. 설정이 없으면 설정 화면으로 이동한다. 실제 활성 상태가 저장되기 전에 성공으로 표시하지 않는다.
- 설정을 AI 연결·이미지 생성·서버·갱신 정책·진단 목록으로 구성했다. 고급 입력은 펼쳐서 사용한다.
- 편집의 이름·번역·저장 방식을 접고, 프로필 항목을 요약 목록으로 변경했다. 본문·변화·검토·버전 기록은 기존 내부 경로를 유지한다.
- Live Sync의 바인딩·갱신 설정을 접고, 에셋 갤러리를 작은 그리드로 변경했다. 보관함은 카드 선택 후 기존 관리 조작을 펼친다.
- 서버 공통 SDK 원본을 바꾸지 않고 LIA 내부 화면에만 밝은 테마를 적용했다.
- Persona 선택 창은 하단 패널로 열리며 배경을 inert 처리한다. 검색창 포커스, Tab 순환, Escape 닫기, 포커스 복귀를 적용했다. 연결 진단은 접어 두되 조회·검증 조작은 유지한다.
- 대기 상태의 내부 진단 문구는 공통 상단에서 숨긴다. 작업 중·성공·오류 메시지는 기존 상태 경로로 표시한다.

## 검증

- Node 문법 검사, LIA GUI 런타임 검사 및 관련 18개 회귀 파일: 총 19개 파일 통과. 전체 회귀 배치는 미실행.
- GUI 검사: 8개 실제 렌더 경로, ID 중복 없음, 기존 조작 버튼, 초안 보존, 호스트 문자열 이스케이프. 새 스위치의 켜기·끄기는 저장소를 재조회했고, 저장 실패 시 기존 enabled 상태가 유지됨을 확인했다.
- 모바일 홈·생성·설정·편집·Live Sync·보관함·에셋·서버·바인딩 화면을 캡처했다. 캡처 과정에서 자료 설정 버튼 겹침, 접힌 에셋 패널의 잔여 높이, 편집 탭 내용 노출을 찾아 수정 후 재촬영했다.
- 브라우저에서 Escape 닫기·포커스 복귀를 확인했다. 1100px 뷰포트에서는 960px 창과 홈 2열 구성을 확인했다.
- `design_samples/lia-pocket/review/index.html`에 예시·이전·수정 후 비교를 보존했다. `regressions.json`에 관련 18개 회귀 결과를 기록했다. GUI 테스트는 별도 실행했다.

검증 화면은 실제 렌더러·헤더·CSS·메뉴 함수를 사용하되 테스트 데이터와 제한된 조작을 사용한다. 서버 화면은 SDK가 만든 초기 마크업을 사용한다. 실제 RisuAI 호스트 GUI, 실제 AI·서버 연결은 미검증이다. 수정 전 원본은 패키지 바깥 `_backups/lia-pocket-refine-20260911`에 보존했다.
